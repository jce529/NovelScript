<move_rules>
회차(chapters.folder_id, D-05: 같은 작품의 category='회차' 폴더 또는 null=회차 루트):
- 대상: 같은 작품의 회차 루트 또는 그 하위 회차 폴더. 회차 루트로 옮기면 folder_id = null.
- 같은 폴더면 no-op 성공. 발행 여부·순서(order_index)는 건드리지 않는다.
- 쓰기 권한(checkWriteAccess)·작품 소유 확인 필수. 서버 액션은 기존 `assertWorkOwnership`/`assertChapterFolder` 패턴 재사용.
설정 문서·폴더(kb_nodes.parent_id):
- 같은 scope·같은 owner·같은 work(또는 둘 다 계정 공유) 안에서만. 잠금 노드(is_locked)는 이동 불가. 템플릿 영역(category='template')과 회차 영역은 이 이동에서 제외(템플릿은 기존 "카테고리 폴더로 이동" 유지).
- 폴더를 자기 자신·자기 하위로 옮기는 순환 금지. 폴더 깊이 한도(`MAX_FOLDER_DEPTH`=32)와 형제 이름 중복(kb_nodes_sibling_name_unique) 준수 → 이름 충돌은 한국어 안내 오류로 반환(자동 개명 금지).
- 같은 카테고리 영역(인물/장소/…) 루트 밖으로 옮기지 않는다(카테고리 의미 보존). 대상은 같은 카테고리의 폴더(루트 포함).
- 0023 정책 가드, 0034 불변식(확정 가지 등)을 우회하지 않는다. 트리거 거부는 사용자에게 한국어 오류로 보여준다. DB 스키마(마이그레이션) 변경 금지.
</move_rules>

<ui_rules>
- 행 메뉴(우클릭·길게 누르기·"…" 버튼): "이동…" 항목 추가(회차 행, 설정 문서·폴더 행). 선택 시 다이얼로그에서 대상 폴더를 고른다(트리 형태 또는 경로 선택, 불가능한 대상은 비활성+사유). 기존 `MoveTemplateFileDialog` 패턴 참고.
- 드래그: `@dnd-kit/core`(이미 의존성) 사용. 마우스/펜 포인터는 8px 이상 이동 시 시작, 터치는 드래그 비활성(길게 누르기는 기존 컨텍스트 메뉴가 쓰므로 충돌 금지). 키보드 센서 지원. 유효한 폴더 위에 올리면 강조, 무효한 곳은 놓을 수 없다. 놓으면 서버 액션 → `router.refresh()`. 실패는 toast.error로 한국어 안내, 트리는 원 상태 유지.
- 드래그 중 행 높이·레이아웃이 흔들리지 않게 한다. 접근성: 드래그 핸들 또는 행에 aria 설명, 이동 결과를 live region/toast로 안내.
- 글자 잘림·겹침 금지: 좁은 폭(375px)에서 긴 이름은 말줄임, 버튼 줄바꿈 없음.
</ui_rules>
