## 요구사항에서 이미 확정된 것 (재논의 없음)

- 자동완성 없음. 발행·공개 작품만 노출.
- 검색창을 누르면 `최근 검색어`(개별·전체 삭제)와 `추천 검색어`(`운영`·`인기` 표시) 분리.
- 탭: 전체·작품·태그·작가. 작품 결과 → 작품 상세. 작가 결과(이름에 키워드 포함 명단) → 작가 페이지.
- 결과 없음: 화면 안 안내 + 다음 행동 버튼(자동 이동 없음, 16번 빈 상태 구성).

## 연동·가정

- **작가 페이지 라우트: `/author/[uuid]`** (`profiles.id`). Phase 28 CONTEXT/UI-SPEC가 확정했고 28이 "Phase 27 검색 작가 결과가 이 URL로 이동"을 명시했다. PLAN에서 이 경로를 명시한다. 28 구현 전에는 링크가 404일 수 있어 구현 순서는 28 → 27 또는 같은 웨이브.
- 최근 검색어: 비로그인 포함 → 저장 위치(로컬 vs 계정) 세부는 UI-SPEC/plan에서 정한다(기본안: 브라우저 `localStorage`, 로그인 시 동기화는 범위 밖).
- 헤더 검색 진입은 Phase 3 독자 헤더(`components/layout/site-header.tsx`, `components/reader/reader-header-frame.tsx`)를 확장.
- 장르는 `lib/works/genres.ts`의 8종 고정 값.
- 라우트 후보: `/search?q=...&tab=all|works|tags|authors` (plan에서 확정).
