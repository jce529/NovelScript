| Boundary | Description |
|----------|-------------|
| Client selection → server resolver | provider/model/keySource는 untrusted intent이며 owner와 key 상태를 서버에서 재조회한다. |
| Vault plaintext → provider SDK | 복호화된 key는 request scope에서 SDK 생성에만 사용한다. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-07 | Spoofing | client `keySource` | mitigate | client flag를 authoritative billing input으로 사용하지 않고 trusted union 반환 |
| T-11-04 | Information Disclosure | Vault secret lifecycle | mitigate | DTO/log/context에 secret 금지, request-scoped decrypt 직후 SDK 생성 |
| T-11-08 | Tampering | invalid key status race | mitigate | expected_key_id conditional RPC |
| T-11-SC | Tampering | package installs | accept | 새 패키지 없음 |
