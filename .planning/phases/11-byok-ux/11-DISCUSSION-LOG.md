## 이번 달 사용량 화면

| 질문 | 선택지 | 선택 |
|------|--------|------|
| 위치 | 설정 페이지 섹션 / 각 제공자 카드 안 / 전용 페이지 | 각 제공자 카드 안 ✓ |
| 금액 통화 | 원화 / USD / (자유 입력) | "토큰으로" → 확인 후 **토큰 수만 표시, 금액 없음** ✓ |
| 월 경계 | KST 매월 1일 00시 / UTC | KST ✓ |
