## Sampling Rate

- **After every task commit:** Run the targeted file(s) from the Per-Task Verification Map via `npx vitest run <file>`
- **After every plan wave:** Run `npx vitest run tests/kb tests/chapters tests/studio tests/ai/mention-search.test.ts`
- **Before `/gsd:verify-work`:** `npm test` (full suite) must be green — `getKbTree`'s split and `category`'s CHECK-constraint widening are cross-cutting enough to risk breaking unrelated suites (e.g. `tests/ai/mention-context.test.ts`) on shared fixtures
- **Max feedback latency:** 60 seconds
