## Spacing / Typography

간격은 4의 배수만 쓴다: 4·8·16·24·32·48·64. 목업의 10·12·14·22px는 8·16·16·24px로 정리한다.

| 용도 | 값 |
|------|----|
| 페이지 컨테이너 | `max-w-6xl`(1152px), 좌우 16px, 상단 24px, 하단 64px, 블록 간 16px(목업 `.wrap`) |
| 행 카드 | 테두리 1px `--border`, 반경 12px, 패딩 16px, 내부 gap 16px |
| 표지 썸네일 | 폭 64px, 비율 3:4, 반경 8px. 표지 없음: 회색 배경(`FeedCard`와 동일) |
| 행 목록 간격 | 행 사이 8px |
| 선호작 | 데스크톱 행 목록(같은 가로형), 행 사이 8px |
| 터치 영역 | 모든 버튼·칩·스위치·X 버튼·서브 행 최소 44×44px (시각 크기가 작으면 패딩으로 히트 영역 확보) |
| 스위치 | 시각 48×28px, 히트 영역 44px 높이 확보 |
| 모바일(<640px) | 좌우 패딩 16px 유지. 행은 `flex-wrap`: 표지+텍스트 한 줄, 행 동작(`이어 읽기` 버튼·스위치)은 아래 줄 전체 폭(목업 `.act{width:100%}`) |

글자 크기는 정확히 4개: **11 / 12 / 14 / 18px**. 굵기는 정확히 2개: **400 / 600**. 본문 line-height 1.5, 제목 1.2.

| 토큰 | 용도 |
|------|------|
| 11px | 배지(`새 회차`, `볼 수 없음`, 상태 배지), 모바일 보조 줄 |
| 12px | 행 메타(`N화 읽는 중 · 총 M화`), 작가 줄, 안내 문구, 스위치 상태 텍스트(`알림 켜짐`), 정렬/필터 칩 |
| 14px | 행 제목, 서브 행, 메인 탭, 버튼, 섹션 소제목(`작품 알림`·`작가 알림`), 빈 상태 본문, 페이지 설명 |
| 18px | 페이지 제목(`이어 읽기` 등), 빈 상태 제목 |

목업의 22px 제목·15px·13px는 위 토큰으로 정리한다. 영문 eyebrow는 두지 않는다(21과 동일).

## Color

60% dominant(`--background`), 30% secondary(행 카드·서브 행 배경·비활성 칩), 10% accent(indigo primary).

accent 전용 요소(이 목록 밖에 쓰지 않는다):
1. 활성 메인 탭 `내서재` 밑줄·글자, 활성 서브 행 항목 글자(21과 동일)
2. 이어 읽기 진도 바 채움(`--primary`), 트랙은 `--muted`
3. `이어 읽기` 주 버튼(행당 1개), 빈 상태의 주 다음 행동 버튼 1개
4. `새 회차` 배지(`--primary` 배경 + `--primary-foreground` 글자, 불투명)
5. 켜진 스위치(`--primary`), 포커스 링

그 외:
- 선택된 정렬·필터 칩은 accent가 아니라 `--foreground` 배경 반전(21의 활성 장르 칩·목업 `.gc.on`과 동일).
- 소장함 상태 배지 `소장중`은 목업의 초록 글자를 쓰지 않고 `Badge` outline(`--foreground` 글자 + 테두리) + 텍스트로 구분한다(새 색 토큰 불가, 색만으로 전달 금지).
- `볼 수 없음` 배지: `--muted` 배경 + `--muted-foreground` 글자.
- **destructive 색은 이 화면에 쓰지 않는다.** X(목록에서 숨기기)는 데이터를 지우지 않는 되돌릴 수 있는 동작이므로 `--muted-foreground` 아이콘 버튼 + 실행 취소 토스트로 처리한다. 오류 문구는 `--foreground` + 테두리.
- 다크 모드는 토큰 자동 반전. 배지·진도 바 대비 4.5:1(트랙·썸네일 위 배지는 불투명 배경)만 확인한다.

## 1. 헤더·진입 (LIB-01)

- 내서재 경로 전체를 `getHeaderVariant`에서 **`reader`(2단: 메인 탭 + 서브 행)** 로 분류한다(21과 동일 요건).
- 활성 메인 탭 `내서재`는 pathname에서 도출한다. 서브 행 4개가 곧 탭이다. `navigation.ts`의 `library` 탭과 서브 행 4개 `href: null`을 아래 경로로 연결한다.
- 서브 행 항목은 `Link`(`aria-current="page"`), 최소 높이 44px, 가로 스크롤(scrollbar 숨김, 포커스 시 `scrollIntoView`). `nav aria-label`은 `내서재 구분`.
- 후보 경로(plan 확정): `/library`(= 이어 읽기, 기본 탭 · 리다이렉트 없이 직접 렌더), `/library/favorites`, `/library/subscriptions`, `/library/owned`. 메인 탭 `내서재`는 `/library`로 간다.
- 탭 이동은 정렬·필터·`page`를 초기화한다(탭마다 쿼리 의미가 다름).
- 비로그인도 헤더·서브 행은 그대로 보이고 서브 행 이동도 허용된다. 본문만 5절의 비로그인 안내를 보인다(D-09).

## 2. 공통 페이지 구성 (위→아래)

1. **제목 블록**: `h1` 18px/600(탭 이름) + 14px `--muted-foreground` 설명 1줄.
2. **컨트롤 줄**(탭별): 선호작 = 정렬 칩 3개, 소장함 = 필터 칩 2개, 그 외 없음.
3. **안내 한 줄**(12px, `--muted-foreground`): 탭별 안내(카피 표).
4. **행 목록**(`ul`/`li`, 행 하나 = `li` 하나).
5. **`더보기` 버튼**(목록 아래 중앙): 남은 항목이 있을 때만. 한 번에 24개, URL `page`는 누적 페이지 수(21의 4절 규칙 동일: `page=3`이면 72개 서버 렌더, `router.push(..., { scroll: false })`, 필터 변경 시 `page` 제거, 잘못된 값 보정, 클릭 중 `불러오는 중…` + `disabled`, 새 첫 행으로 포커스 이동, `aria-live` `{n}개 더 불러왔어요`).
6. 결과 건수는 `aria-live="polite"` 시각 숨김 영역에 `{n}개`(이어 읽기·선호작: `작품 {n}개`, 소장함: `작품 {n}개`).

URL 쿼리: 정렬 `sort`(선호작: `updated`(기본, URL 생략) | `added` | `title`), 소장함 필터 `own`(`all`(기본, 생략) | `owned`), `page`. 알림 구독 탭은 두 섹션 모두 자체 `더보기`를 갖지 않고 각 섹션 상위 24개 + 섹션별 `더보기`(`page`는 `workPage`/`authorPage` 두 키로 분리; plan 확정). 정렬·필터·탭·페이지는 새로고침·공유·뒤로 가기에서 복원된다.

## 3. 탭별 행 구조 (공통 `LibraryRow`)

```
[표지 64×(3:4)] | 제목(14/600, 1줄 말줄임) + 배지 | 메타(12px) | [진도 바] | 행 동작(오른쪽)
```

- 행 전체가 링크는 아니다. **제목·표지**가 작품으로 가는 `Link`이고, 행 동작(버튼·스위치·X)은 별도 컨트롤이다(중첩 인터랙티브 금지). 표지 `alt`는 `{작품명} 표지`, 제목 링크와 표지 링크는 하나의 `Link`로 묶어 탭 정지 1개로 한다.
- 작가 필명이 필요한 곳은 `profiles.pen_name`, 없으면 `작가`.

### 3-1. 이어 읽기 (LIB-02, D-05·D-06)

| 요소 | 규칙 |
|------|------|
| 정렬 | 최근 읽은 순(고정, 정렬 컨트롤 없음) |
| 진도 바 | 높이 6px, 반경 full, 채움 `--primary`. `읽은 마지막 회차 순번 / 공개 회차 수`(0~100%로 클램프). `role="progressbar"` + `aria-valuenow`/`aria-valuemin=0`/`aria-valuemax=100` + `aria-label="{작품명} 진도"` |
| 메타 | `{N}화 읽는 중 · 총 {M}화 · {상대 시각}` (예: `12화 읽는 중 · 총 18화 · 2시간 전`). 100%(마지막 회차까지 읽음)이면 `완독 · 총 {M}화 · {상대 시각}`, 진도 바 100% |
| 주 버튼 | `이어 읽기` (`Button` primary, 마지막 읽은 회차 뷰어로 이동. 완독이면 라벨을 `다시 읽기`로 바꾸고 outline) |
| 보조 | `자세히`(outline, 작품 상세 `/works/{id}`) — 목업 유지 |
| X | 오른쪽 끝 아이콘 버튼 `X` 16px, 히트 44px, `aria-label="{작품명} 이어 읽기 목록에서 숨기기"`. 클릭 즉시 행 제거(낙관적) + 토스트 `이어 읽기 목록에서 숨겼어요` + 액션 `실행 취소`(유지 5초). 취소하면 `hidden_at` 해제하고 같은 위치로 복원. 실패 시 행 복원 + 토스트 `숨기지 못했어요. 다시 시도해 주세요.` |
| 볼 수 없음 | 마지막 읽은 회차가 숨겨진(블라인드·비공개) 회차이면 제목 옆에 `볼 수 없음` 배지(11px, muted), 메타는 `{N}화 읽는 중 · {상대 시각}`(총 화수·진도 바 숨김), `이어 읽기` 버튼은 `disabled` + `aria-disabled`, 대신 `자세히` 버튼만 활성. 빈 칸을 남기지 않는다 |
| 모바일 | 버튼 줄이 아래로 내려가 `이어 읽기`(flex-1) + `자세히`, X는 첫 줄 오른쪽 위에 유지 |

### 3-2. 선호작 (LIB-03, D-03·D-04)

| 요소 | 규칙 |
|------|------|
| 정렬 칩 | `최근 업데이트순`(기본) · `최근 추가순` · `제목순`. 단일 선택, `aria-pressed`(`radiogroup` 패턴, 방향키 이동), 선택 시 `sort` 설정·`page` 제거 |
| 행 구성 | 표지 + 제목 + `새 회차` 배지(accent, 제목 오른쪽 인라인) + 메타 + (오른쪽) `읽기`/`이어 읽기` 버튼 |
| 메타 | `{M}화 · {상대 업데이트}` (예: `12화 · 어제 업데이트`, `9화 · 3일 전`) |
| `새 회차` 배지 | D-03 규칙으로 호출측이 계산해 `boolean`으로 넘긴다. 텍스트 `새 회차`, 색만으로 전달 금지 |
| 버튼 | 읽은 기록이 있으면 `이어 읽기`(마지막 읽은 회차), 없으면 `첫 화 읽기`. 둘 다 outline. `새 회차`가 있으면 버튼은 primary |
| 안내 | `새 회차가 올라온 작품에는 표시가 붙어요.` |

### 3-3. 알림 구독 (LIB-04, D-01·D-02)

두 섹션을 위→아래로 둔다. 각 섹션은 14px/600 소제목 + 행 목록 + 12px 안내.

**작품 알림**

| 요소 | 규칙 |
|------|------|
| 행 | 표지 + 제목 + 메타(12px) + 오른쪽 스위치 + 상태 텍스트 |
| 메타 | 연재 주기 데이터가 있으면 `매주 월·목 연재`, 없으면 최근 공개일 `최근 회차 {M}화 · {상대 시각}`. 완결작은 `완결 · 알림 받을 회차 없음` |
| 스위치 | `Switch`, `aria-label="{작품명} 새 회차 알림"`. 켜짐=`알림 켜짐`, 꺼짐=`알림 꺼짐`(12px, 스위치 왼쪽, `aria-live="polite"` 없이 스위치 상태로 전달) |
| 토글 | 낙관적 전환 → 서버 액션(`notify` 반전). 토스트 켬 `새 회차 알림을 켰어요.` / 끔 `새 회차 알림을 껐어요.`. 실패 시 롤백 + `알림 설정을 바꾸지 못했어요. 다시 시도해 주세요.`. 처리 중 스위치 `disabled` |
| 꺼도 | 행은 목록에 남는다. 목록에서 사라지는 동작 없음 |
| 안내 | `알림을 끄면 새 회차가 올라와도 알려드리지 않아요. 선호작과 알림 구독은 따로 관리돼요.` |

**작가 알림**

| 요소 | 규칙 |
|------|------|
| 행 | 아바타 원 40px(필명 첫 글자, 그라디언트 원, `aria-hidden`) + 필명(`Link` → `/author/{authorId}`) + 메타 + 스위치 + 상태 텍스트 |

## 7. 접근성

- 모든 인터랙티브 요소(서브 행, 칩, 버튼, X, 스위치, `더보기`, `다시 시도`) 최소 **44×44px** 히트 영역.
- 포커스 링 2px indigo(`--ring`), `outline-offset: 2px`, `overflow:hidden`에 잘리지 않게 행 바깥쪽.
- `h1` 하나. 각 섹션(`작품 알림`·`작가 알림`)은 `h2`, 행 제목은 `h3`. 목록은 `ul`/`li`. 알림 구독 탭의 두 섹션은 `section aria-labelledby`.
- 서브 행 `nav aria-label="내서재 구분"`, 활성 `aria-current="page"`. 칩 줄은 `radiogroup` 패턴(방향키).
- 스위치는 `role="switch"` + `aria-checked`, 상태 텍스트와 이중 전달(색만으로 구분 금지). 진도 바는 `progressbar` + 텍스트 메타 병기.
- X 후 포커스는 다음 행의 X(없으면 이전 행, 목록이 비면 빈 상태 주 버튼)로 이동. 실행 취소 토스트는 `role="status"`/`aria-live="polite"`.
- `볼 수 없음` 행의 비활성 `이어 읽기`는 `aria-disabled` + 이유를 `aria-describedby`로 연결(`볼 수 없는 회차예요`).
- `prefers-reduced-motion`: 스위치 이동 transition·스켈레톤 pulse·행 제거 애니메이션 끔.
- 색만으로 상태 전달 금지: `새 회차`·`볼 수 없음`·`소장중`·`알림 켜짐/꺼짐` 모두 텍스트.

## Claude's discretion / 확인 필요

1. **경로 형태**: `/library`(이어 읽기) + `/library/favorites|subscriptions|owned` 세그먼트를 권장(pathname으로 활성 탭 도출, 21의 `/series/free`와 일관). `/library?tab=` 방식도 동등하며 plan이 정한다. 기본 탭 리다이렉트는 두지 않고 `/library`가 이어 읽기를 직접 렌더.
2. **신규 `switch` 컴포넌트**: 28은 `aria-pressed` 버튼, 목업은 스위치. 설정형 on/off는 switch 의미가 맞아 shadcn 공식 `switch`를 추가하도록 권장. 추가 불가 시 `button role="switch"`로 동일 시각·접근성 구현.
3. **작가 알림 메타**: 28 조회 DTO(`authorId`, `penName`, `notify`, `subscribedAt`)에 작품 수·구독자 수가 없다. DTO에 없으면 `구독한 날 {YYYY.MM.DD}`로 대체(28 PLAN 확인 후 plan이 확정).
4. **완독 시 버튼 라벨**(`다시 읽기`)과 선호작의 `첫 화 읽기`: 목업에 없는 보강 문구.
5. **소장함 카피 교정**: 대여 언급 제거(`소장한 회차가 없어요`)와 안내 `소장한 회차는 기간 제한 없이 언제든 다시 볼 수 있어요.` — Phase 33이 대여 문구로 확장.
6. **알림 구독 탭 페이지네이션**: 섹션별 24개 + 섹션별 `더보기`, `page` 키 분리(`workPage`/`authorPage`). 항목 수가 적으면 plan이 한 번에 전체 노출로 단순화해도 된다.
7. **상대 시각 표기**: `방금`·`{n}분 전`·`{n}시간 전`·`어제`·`{n}일 전`, 7일 초과는 `YYYY.MM.DD`(기존 유틸이 있으면 재사용).
8. **홈 `RecentlyReadSection`**: 숨긴 기록 제외 여부는 같은 조회 함수를 쓰면 함께 반영(UI 변경 없음).
9. 목업의 `실행 취소` 토스트는 없었다(목업은 `기록을 삭제했어요.`만). D-06의 실행 취소 요구에 맞춰 카피를 위처럼 확정했다 — 목업 문구 `기록을 삭제했어요.`는 쓰지 않는다(실제로는 숨김이므로).
