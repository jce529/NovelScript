## 1. 준비물 (사람이 해야 하는 것)

1. **터널 도구**: 이 PC에는 `cloudflared`가 없다. 인수를 진행하는 PC에 설치하거나(무료 quick tunnel) 다른 터널을 쓴다. 포트는 `3100`만 연다.
2. **일회용 Supabase 대시보드**(`anzafn…`) 접근: Authentication → URL Configuration의 **Site URL을 터널 origin으로, Redirect URLs를 같은 origin으로** 바꾼다. 끝나면 원래 값(`http://localhost:3100`)으로 복구하고 Redirect URLs는 비운다.
3. **Claude에 로그인한 브라우저**: claude.ai 커스텀 커넥터를 등록할 수 있는 계정(Pro). 쓰기 도구 승인은 Claude의 기본 권한("승인 필요")이 그대로 보인다.
4. **임시 작가 세션**: 소셜 로그인 없이 `@novelscript.test` 임시 작가로 `/studio`에 들어가는 쿠키가 필요하다. Phase 12·13에서는 세션 쿠키를 만드는 임시 스크립트(저장소 밖 scratchpad의 `mint-writer-session.mjs`)를 썼고 이 저장소에는 없다. 필요하면 새로 만들어 달라고 요청한다(테스트 헬퍼 `createTestUser`/`signedInClient` 기반).
5. `.env.disposable`(워크트리 루트, 미커밋)과 `node_modules`. 확인은 `node scripts/check-env.mjs .env.disposable`만 쓴다. API·DB URL 둘 다 `anzafn`인지 확인하고 시작한다.
6. 다른 환경과 **동시에** 일회용 DB 테스트를 돌리지 않는다(클라이언트 등록 한도 429).
