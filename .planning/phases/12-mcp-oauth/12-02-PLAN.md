DB 테스트 파일에는 `vitest.config.ts` 분류용 `SUPABASE_DB_URL` 마커와 공유 ref 차단 검사를 명시한다(D-06, D-09~10, D-14, D-19~21).</action>
  <verify><automated>rg -n 'security definer|set search_path|mcp_authorize_call|mcp_disconnect|mcp_connect' supabase/migrations/0037_mcp_oauth_grants.sql; git diff --check</automated></verify>
