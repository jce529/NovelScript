- **숨긴 부모의 공개 하위 가지:** 규칙 17의 “비공개 전환은 하위 가지에 전파하지 않는다”는 확정이다. 재부착 여부·대체 조상은 정해져 있지 않다. **기본안 / 사용자 확인 필요:** 하위의 공개 작품은 독립된 가시 컴포넌트로 표시하되 숨긴 부모/분기 연결선/부모 ID·이름·시점은 반환하지 않는다. 보이는 조상으로 재부착하지 않는다. 원본 parent_branch_id와 자식 공개 값은 유지하며 단순 필터로 자식을 사라지게 하지 않는다. “연결 정보 비공개”로 설명한다.
- **숨긴 가지 작품의 피드·직접 URL:** 규칙 8은 연결 노출만 말하며 규칙 17은 하위 비전파만 답한다. **기본안 / 사용자 확인 필요:** 숨긴 가지 자신의 작품은 독자 피드·작품 URL·회차 메타/본문/RPC에서 비노출(unavailable). 소유자 스튜디오와 검증된 관리자 세계수는 유지하고 공개 하위 가지 작품의 가시성은 독립 판정한다. 숨김을 admin_blinded나 하위 공개 상태로 덮어쓰지 않는다.
