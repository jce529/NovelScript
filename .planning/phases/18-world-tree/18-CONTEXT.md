# Phase 18 — 세계수: 선행 결정 (2026-10-12)

설계 원본은 `.planning/design/WORLD-TREE.md`(규칙 1~21), 요구사항 WTREE-01~08·10. 이 문서는 plan 전에 확정해야 했던 선행 공백 3건의 결정이다.

## 결정

- **세계관 탭(작품 상세 4탭):** Phase 3 정합 보완이 4탭 셸(소개·회차·세계관·리뷰)을 만든다. Phase 18은 그 `세계관` 탭 안에 `세계수` 보기를 채운다. 따라서 Phase 18 plan은 Phase 3 보완의 4탭 셸 완료를 선행으로 둔다.
- **세계관 공개 설정 화면:** **Phase 18이 최소 버전을 직접 만든다.** 범위는 가지 치기 시작 위치인 작품 설정 화면의 `이 세계관에서 가지 치기` 버튼과 세계수 연결 공개 토글(WTREE-07)까지. 문서별 공개 스위치·등장 회차·세부 항목 잠금(READ-06, WTREE-09)은 후속 Lore 위키 phase로 남긴다.
- **열매 크기 지표(WTREE-08):** 완독 데이터 phase가 생기기 전에는 **현행 피드 점수 지표(조회·좋아요·다음화 이동률)** 로 임시 산출한다. 지표 어댑터를 한 곳에 두어 완독률·연독률 데이터가 생기면 그 어댑터만 교체한다. 작가 본인 조회 제외 규칙은 유지한다.

## 파급

- Phase 18 의존성: Phase 2(설정집, 읽기 전용 템플릿 정책 반영), Phase 3 보완(4탭 셸).
- WTREE-08 요구 문구의 "독자 수·완독률·연독률"은 임시로 현행 지표를 쓴다는 주석을 plan에서 남긴다.

## Open Decisions 논의 (2026-10-13)

18-11 PLAN의 `Open Decisions` 3건 중:

- **확정 — 연결 공개 토글 단위:** 가지 연결 한 개당 `connection_public`(기본 true). 루트 전체를 끄는 두 번째 플래그는 만들지 않는다. 작품 설정 화면과 가지 치기 4단계가 같은 가지 값을 편집한다.
- **논의 중 — 숨긴(비공개) 부모 아래의 공개 하위 가지:** 기본안(독립 컴포넌트로 표시, 부모 정보 비노출, 재부착 없음)은 확정하지 않는다. 사용자 의견: 부모가 공개되지 않았다면 애초에 세계관 편입이 되지 않는 것 아닌가 — 세부 논의 후 확정.
- **논의 보류 — 숨긴 가지 작품의 피드·직접 URL 노출:** 위 쟁점 논의 후 "왜 숨기는가"를 먼저 정한 뒤 진행한다.
