## Open Decisions

아래는 확정 정책이 아닌 **기본안 / 사용자 확인 필요**이다. 미확인 상태에서는 정보가 새지 않는 기본안을 구현·검증하되, 공개 출시 승인은 18-12 체크포인트에서 받는다. WORLD-TREE 규칙 1~21이 RESEARCH의 추천보다 우선한다.

- **연결 공개 토글 단위:** 규칙 8은 단위를 명시하지 않고 규칙 19는 구매 가지에만 적용되어 셀프 가지의 답이 되지 않는다. **기본안 / 사용자 확인 필요:** 가지 연결 한 개 단위 connection_public(기본 true). 작품 설정 화면과 가지 치기 4단계가 같은 가지 값을 편집한다. 루트 전체를 끄는 두 번째 플래그는 만들지 않는다. 루트에서 가지가 없으면 토글 대상 없음으로 표시한다. 규칙 17에 따라 자식 값을 바꾸거나 비공개를 전파하지 않는다. 모든 잔가지 숨김 상태에만 UI-SPEC의 “본가지 작품만 보여요” 문구를 쓰고 부분 숨김은 해당 가지 숨김 문구로 제한한다.
- **숨긴 부모의 공개 하위 가지:** 규칙 17의 “비공개 전환은 하위 가지에 전파하지 않는다”는 확정이다. 재부착 여부·대체 조상은 정해져 있지 않다. **기본안 / 사용자 확인 필요:** 하위의 공개 작품은 독립된 가시 컴포넌트로 표시하되 숨긴 부모/분기 연결선/부모 ID·이름·시점은 반환하지 않는다. 보이는 조상으로 재부착하지 않는다. 원본 parent_branch_id와 자식 공개 값은 유지하며 단순 필터로 자식을 사라지게 하지 않는다. “연결 정보 비공개”로 설명한다.
- **숨긴 가지 작품의 피드·직접 URL:** 규칙 8은 연결 노출만 말하며 규칙 17은 하위 비전파만 답한다. **기본안 / 사용자 확인 필요:** 숨긴 가지 자신의 작품은 독자 피드·작품 URL·회차 메타/본문/RPC에서 비노출(unavailable). 소유자 스튜디오와 검증된 관리자 세계수는 유지하고 공개 하위 가지 작품의 가시성은 독립 판정한다. 숨김을 admin_blinded나 하위 공개 상태로 덮어쓰지 않는다.

WTREE-08은 CONTEXT의 “현행 피드 점수 지표(조회·좋아요·다음화 이동률)로 임시 산출” 결정에 따라 한 곳의 지표 어댑터로 임시 구현한다. 완독률·연독률 데이터가 생기면 어댑터만 교체한다. 과거 누적 조회에서 작가 조회를 소급 분리할 자료가 없어 이후 인증 조회부터 제외하고 기준 시각을 명시한다. 비로그인 작가의 조회는 식별 불가하며 이를 해결했다고 주장하지 않는다.
