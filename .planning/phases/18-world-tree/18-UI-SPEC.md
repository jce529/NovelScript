## Color

기본은 기존 neutral + indigo 토큰이며 accent(indigo)는 주 버튼·선택 상태·포커스에만 쓴다. 세계수 전용으로 아래 **시각화 토큰**만 추가한다(UI 크롬이 아니라 데이터 표현):

| 토큰 | 용도 | 비고 |
|------|------|------|
| `--tree-trunk` (갈색) | 본가지 | 굵기로 중요도 표현 |
| `--tree-branch-if` (황갈색 계열) | If 가지 | 가지마다 약간 다른 명도 허용 |
| `--tree-branch-expand` (초록) | 확장 가지 | If 가지와 색으로 구분, 색에만 의존하지 않도록 상세에 유형 텍스트 병기 |
| `--tree-fruit-*` (열매 팔레트 8색) | 작품(열매) | 색은 구분용일 뿐이며 의미는 열매 안 글자와 상세로 전달 |
| 선택 강조 | 선택한 열매·가지 | accent 외곽선(3px) |

다크 모드에서는 대비를 별도 확인한다. 색만으로 구분되는 정보(If/확장)는 항상 텍스트 칩으로 병기한다.

## 1·2. 세계수 보기

### 구성

- 가로 본가지에 열매가 세계관 내 시간순(왼쪽=과거, 오른쪽=최신)으로 맺힌다. 같은 시기 병렬 작품은 `동시 진행`으로 가지 위·아래에 나란히 매달린다.
- 잔가지는 분기점에서 위·아래로 갈라진다. 굵기=본가지와의 근접도·파생 규모, 열매 크기=작품 인기(WTREE-08).
- 시대 구간 눈금 라벨을 하단에 둔다. 범례: `굵기 = 본가지와의 근접도 · 열매 크기 = 인기 · 초록 = 확장 가지`와 `산식은 임시안` 칩.
- 데스크톱: 좌 캔버스 + 우 상세 패널(340px). 모바일: 캔버스는 가로 스크롤, 하단 상세 시트에 선택 항목 상세.

### 선택·상세

| 항목 | 상세에 표시 |
|------|-------------|
| 열매(작품) | 종류 칩(원작·프리퀄·속편·외전·동시 진행·셀프 가지·확장 가지), 세계관 내 시점, 인기(임시 지수), 속한 가지, 연재 상태, `작품 보러 가기` 버튼 |
| 가지 | 종류(본가지/If/확장), 근접도, 변경한 설정 문서 수, 인기, 굵기, `스냅샷 고정` 칩 + 안내문 |
| 본가지 | 열매 수·잔가지 수, 판매·편입은 이 phase 범위 밖이라 표시하지 않음 |

### 카피

| 요소 | 문구 |
|------|------|
| 제목 | `{작품 이름} 세계수` |
| 도움말 | `가지 = 설정 흐름 · 열매 = 작품 · 오른쪽 끝일수록 세계관 내 최신 · 같은 시점에 함께 벌어진 작품은 가지 위·아래에 나란히 매달려요` |
| 스냅샷 안내 | `분기 시점 스냅샷으로 고정돼요. 원작 설정이 바뀌어도 이 가지에는 반영되지 않아요.` |
| 모바일 스크롤 힌트 | `좌우로 밀어 보기 →` |
| 작가 버튼 | `연표 편집`, `이 세계관에서 가지 치기` |
| 독자 보기 + 연결 공개 꺼짐 | `작가가 연결 공개를 꺼서 잔가지는 안 보이고 본가지 작품만 보여요.` |

### 상태

| 상태 | 처리 |
|------|------|
| 가지가 없고 작품 1편 | 본가지 + 열매 1개만 그리고 `아직 갈라진 가지가 없어요`를 안내 (작가에게는 가지 치기 버튼 노출) |
| 연결 공개 꺼짐 + 독자 | 잔가지·잔가지 열매를 숨기고 안내 배너 표시 (WTREE-07) |
| 작가 본인·관리자 | 연결 공개 여부와 무관하게 전체 표시 |
| 열매가 매우 많음(구간당 다수) | 겹침 방지를 위해 구간 안 순서대로 간격 배치, 스크롤. 성능 기준은 플랜에서 정함 |
| 로딩 / 실패 | 스켈레톤 트리 / `세계수를 불러오지 못했어요. 다시 시도해 주세요.` + 재시도 버튼 |

### 접근성

- 캔버스의 열매·가지는 버튼이며 `aria-label`에 이름·종류를 넣는다. 키보드는 Tab으로 이동하고 Enter로 선택한다.
- 시각 트리 외에 **목록 보기**(시간순 열매 목록)를 대체 수단으로 제공한다(구현은 플랜에서 결정, 화면 구성은 상세 패널 재사용).
- 색만으로 If/확장을 구분하지 않는다.

## 3. 연표 편집

- 상단: `세계관 연표` 제목, 설명, `+ 시대 구간 추가`, `연표 저장`. 가지별 연표 탭(본가지 / 가지 A …).
- 시대 구간은 열. 각 열 머리: 구간 이름, `{n}편` 칩, 연도 입력(선택), 설명.
- 작품 카드: 점 색, 제목, 종류 칩, `동시 진행` 칩(구간의 첫 작품은 표시 불가). 선택하면 하단 바에서 `← 이전 구간으로`, `다음 구간으로 →`, `구간 안에서 ↑`, `↓`, `앞 작품과 동시 진행 / 해제`.
- 이어받은 구간(분기 시점까지)은 점선·회색 잠금이며 수정 불가. 시도 시 토스트 `이어받은 구간은 수정할 수 없어요. 분기 이후 구간에서 편집해 주세요.`
- 잔가지의 독립 구간에는 `본가지 대응 메모(선택)` 입력이 있다(WTREE-02). 본가지 탭·이어받은 구간에는 없다.
- 드래그 이동은 구현 단계에서 지원하고 버튼 이동은 접근성 대체 수단으로 유지한다.

| 카피 | 문구 |
|------|------|
| 설명 | `시대 구간은 필수(이름·순서), 연도 숫자는 선택이에요. 작품(열매)을 구간에 배치하고, 같은 시기에 함께 벌어진 작품은 동시 진행으로 표시해요.` |
| 연도 placeholder | `연도(선택) 예: 세계력 120~180년` |
| 메모 placeholder | `예: 본가지 3기 후반에 해당` |
| 첫 작품 동시 진행 시도 | `구간의 첫 작품은 동시 진행으로 표시할 앞 작품이 없어요.` |
| 저장 완료 | `연표를 저장했어요. 세계수에 열매 위치가 반영돼요.` |
| 하단 안내 | `연표를 비교하고 싶을 때는 세계수 보기에서 가지의 분기점을 기준으로 이어서 봐요. 연표가 가지마다 독립이라 구간 이름이 같아도 가지끼리 시점이 일치한다고 보장하지 않아요.` |

## 4. 가지 치기 흐름 (5단계)

| 단계 | 내용 | 막는 조건 |
|------|------|-----------|
| 1. 세계수 시작 | 시작 위치(이 phase에서는 `내 작품의 세계관`만 활성), 유형 선택: If 가지 / 확장 가지, 복제 범위 안내(설정집 전체 복제, 본문·원고는 복제 안 함) | — |
| 2. 설정 복제·수정 | 복제한 설정 문서 목록에서 수정·삭제·`+ 새 인물/장소/설정 문서`. 확장 가지는 기존 문서 수정·삭제 버튼 비활성 | — |
| 3. 변경 확인 | 유형 칩 + 수정/삭제/추가 건수 + 변경 목록, 스냅샷·되돌릴 수 없음 경고 | If: 변경 0건이면 `변경 내용 확인` 비활성. 확장: 추가 0건이면 비활성 |
| 4. 새 작품 정보 | 제목, 세계관 내 시점(연표 구간), 세계수 연결 공개(공개 기본 / 숨김) | 제목 비어 있음 |
| 5. 완료 | `가지가 열렸어요`, `세계수에서 보기` / `에디터로 가서 연재 시작` | — |

| 카피 | 문구 |
|------|------|
| If 가지 설명 | `기존 설정을 고치거나 지우고, 필요하면 새 설정도 더해요. 같은 세계관의 다른 가능성(If 스토리)을 써요.` |
| 확장 가지 설명 | `기존 설정은 그대로 가져오고 새 인물·장소 같은 설정만 더해요. 같은 세계관을 공유하는 다른 지역 이야기를 써요.` |
| If 0건 토스트 | `설정을 하나 이상 바꿔야 가지를 확정할 수 있어요.` |
| 확장 0건 토스트 | `새 설정을 하나 이상 추가해야 가지를 확정할 수 있어요.` |
| 확정 경고 | `확정하면 이 시점의 설정이 스냅샷으로 고정돼요. 원본 세계관이 나중에 바뀌어도 이 가지에는 반영되지 않고 알림만 가요. 확정 뒤에는 가지 설정을 되돌릴 수 없어요.` |
| 연결 공개 도움말 | `숨겨도 작가 본인과 관리자에게는 연결이 보여요.` |

실제 문서 편집은 스튜디오 에디터에서 이어지고 이 흐름은 변경 판정과 확정만 담당한다.

### 파괴적 액션

- **가지 확정**: 되돌릴 수 없는 액션이므로 3단계에서 경고를 읽고 `가지 확정하기`를 눌러야 4단계로 간다. 별도 확인 다이얼로그는 두지 않는다(경고 박스가 확인 역할).
- **삭제**(WTREE-10): 하위 가지가 있는 가지·작품의 삭제 버튼은 비활성이며 툴팁 `하위 가지를 먼저 정리해 주세요.` 하위가 없으면 기존 삭제 확인 패턴을 따른다. 비공개 전환은 하위에 전파되지 않으며 전환 확인 문구에 `하위 가지에는 영향이 없어요`를 포함한다.

## 5. 연결 공개 설정

- 가지 치기 4단계와 세계관 공개 설정에서 토글: `공개 (기본)` / `숨김`.
- 숨김 시 독자에게 잔가지가 안 보이고 본가지만 보인다. 작가·관리자는 전체. 독자 보기 미리보기에서 `연결 공개: 켜짐/꺼짐`으로 결과를 확인할 수 있다.

## Interaction Contract

| 트리거 | 동작 |
|--------|------|
| 열매·가지 선택 | 선택 외곽선 + 상세 갱신(데스크톱 우측 패널, 모바일 하단 시트). 같은 항목 재선택은 유지 |
| `작품 보러 가기` | 해당 작품 상세로 이동(스포일러 잠금은 기존 세계관 탭 규칙을 따름. 가지 확장 잠금은 WTREE-09 별도) |
| 독자 보기 전환(작가 전용 미리보기) | 작가 보기 ↔ 독자 보기, 독자 보기에서 연결 공개 on/off 확인 |
| 연표 저장 | 구간 순서·동시 진행·연도·메모 저장 후 세계수 열매 위치 갱신 |
| 가지 확정 | 서버에서 변경·추가 건수를 재검증(0건이면 거부), 스냅샷 생성, 새 작품과 연표 위치 생성 |
| 모바일 | 캔버스 가로 스크롤, 상세는 하단 시트, 시트는 캔버스를 가리지 않도록 최소 높이 유지 |

## Open Items (플랜 전 확인)
