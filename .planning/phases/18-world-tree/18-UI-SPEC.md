## Spacing / Typography

기존 간격 스케일을 그대로 쓴다(4의 배수). 글자 크기는 11/12/14/18px 네 토큰, 굵기는 400/600으로 제한한다. 11px은 캔버스 열매 라벨·보조 정보, 12px은 보조 설명, 14px은 본문·버튼, 18px은 제목에 쓴다. 본문 line-height는 1.55다. 목업 CSS의 임시 글자 크기는 구현 시 이 네 토큰으로 정리한다. 핵심 정보는 하단 상세 시트(모바일)·우측 패널(데스크톱)의 14px 본문에 둔다. 모바일 터치 영역은 44px 이상이며 34px stub 원도 별도 44px 이상 히트 영역을 둔다.

## Color

색 비율은 60% dominant(neutral 기본 배경), 30% secondary(카드·상세 패널·탭), 10% accent(indigo)로 선언한다. accent는 주 버튼·선택 상태·포커스에만 쓴다. 세계수 전용으로 아래 **시각화 토큰**만 추가한다(UI 크롬이 아니라 데이터 표현):

| 토큰 | 용도 | 비고 |
|------|------|------|
| `--tree-trunk` (갈색) | 본가지 | 굵기로 중요도 표현 |
| `--tree-branch-if` (황갈색 계열) | If 가지 | 가지마다 약간 다른 명도 허용 |
| `--tree-branch-expand` (초록) | 확장 가지 | If 가지와 색으로 구분, 색에만 의존하지 않도록 상세에 유형 텍스트 병기 |
| `--tree-fruit-*` (열매 팔레트 8색) | 작품(열매) | 색은 구분용일 뿐이며 의미는 열매 안 글자와 상세로 전달 |
| `--tree-broken` | 부러진 가지 끝 점선·stub 원 점선 | 목업 기준 `#a8a29e` 계열. 밝은 배경에서는 대비 확보값 `#78716c`, 다크 모드는 `#a8a29e`(neutral dark 배경). 인접 배경 대비 3:1 이상, 라벨은 기존 foreground로 4.5:1 이상. `부러진 가지`·`비공개된 본작 자리` 텍스트 병기 |
| 선택 강조 | 선택한 열매·가지 | accent 외곽선(3px) |

다크 모드에서는 대비를 별도 확인한다. 색만으로 구분되는 정보(If/확장)는 항상 텍스트 칩으로 병기한다.

## 1·2. 세계수 보기

### 구성

- 가로 본가지에 열매가 세계관 내 시간순(왼쪽=과거, 오른쪽=최신)으로 맺힌다. 같은 시기 병렬 작품은 `동시 진행`으로 가지 위·아래에 나란히 매달린다.
- 잔가지는 분기점에서 위·아래로 갈라진다. 굵기=본가지와의 근접도·파생 규모, 열매 크기=작품 인기(WTREE-08).
- 시대 구간 눈금 라벨을 하단에 둔다. 범례: `굵기 = 본가지와의 근접도 · 열매 크기 = 인기 · 초록 = 확장 가지`와 `산식은 임시안` 칩.
- 데스크톱: 좌 캔버스 + 우 상세 패널(340px). 모바일: 트리 영역은 340px 고정·가로 스크롤, 하단 상세 시트는 상단 UI를 제외한 나머지 높이(최소 220px)로 항상 표시한다. 선택이 바뀌면 시트 내용만 교체하고 시트 내부를 스크롤하며 포커스는 시트 제목(`tabindex="-1"`)으로 이동한다.
- 독자 보기에서 부모 작품이 비공개이면 본가지는 잔가지가 붙지 않는 최신 쪽 맨 끝에서 점선으로 부러진다(데스크톱 4px, 모바일 3px). 그 끝 위쪽에 `부러진 가지` 라벨을 둔다. 모든 잔가지는 끊기지 않은 본가지에 붙어 있고 기존 파생 연결을 유지한다.
- 비공개된 원작 열매는 원래 시점 자리에 점선 `?` 원(stub)으로 남긴다. 인기와 무관한 고정 지름은 데스크톱 44px·모바일 34px이며 아래에 `비공개된 본작 자리` 라벨을 둔다. 실제 작품 열매·이름·표지·회차·ID는 독자에게 노출하지 않는다. `?` 글리프는 `aria-hidden="true"`다.

### 선택·상세

| 항목 | 상세에 표시 |
|------|-------------|
| 열매(작품) | 종류 칩(원작·프리퀄·속편·외전·동시 진행·셀프 가지·확장 가지), 세계관 내 시점, 인기(임시 지수), 속한 가지, 연재 상태, `작품 보러 가기` 버튼 |
| 가지 | 종류(본가지/If/확장), 근접도, 변경한 설정 문서 수, 인기, 굵기, `스냅샷 고정` 칩 + 안내문 |
| 본가지 | 공개된 열매 수·잔가지 수, 판매·편입은 범위 밖 |
| stub(독자) | 종류 `비공개된 작품 자리`, 제목 `비공개된 가지`, 칩 `비공개`, 본문 `원래 본작이 있었던 자리예요. 이어진 작품은 계속 볼 수 있어요.`. 일반 안내만 표시하며 세계관 내 시점·이어진 가지 개수 등 지표/사실 항목은 모두 숨긴다. 작품명·표지·회차·ID·작품 링크 없음 |

### 카피

| 요소 | 문구 |
|------|------|
| 제목 | `{발행된 진입 작품 이름} 세계수` (비공개 root 이름은 쓰지 않고 필요하면 `세계수`) |
| 도움말 | `가지 = 설정 흐름 · 열매 = 작품 · 오른쪽 끝일수록 세계관 내 최신 · 같은 시점에 함께 벌어진 작품은 가지 위·아래에 나란히 매달려요` |
| 스냅샷 안내 | `분기 시점 스냅샷으로 고정돼요. 원작 설정이 바뀌어도 이 가지에는 반영되지 않아요.` |
| 모바일 스크롤 힌트 | `좌우로 밀어 보기 →` |
| 작가 버튼 | `연표 편집`, `이 세계관에서 가지 치기` |
| 독자 미리보기 | `독자에게 어떻게 보이는지 확인해요.` |
| 부러진 가지 라벨 | `부러진 가지` |
| stub 자리 라벨 | `비공개된 본작 자리` |
| stub 상세 종류 / 제목 / 칩 | `비공개된 작품 자리` / `비공개된 가지` / `비공개` |
| stub 상세 본문 | `원래 본작이 있었던 자리예요. 이어진 작품은 계속 볼 수 있어요.` |
| 작가 보기 비공개 작품 안내 | `독자에게는 이 자리가 ‘부러진 가지’로 보여요. 다시 발행하면 가지가 이어져요.` |

### 상태

| 상태 | 처리 |
|------|------|
| 가지가 없고 작품 1편 | 본가지 + 열매 1개만 그리고 `아직 갈라진 가지가 없어요`를 안내 (작가에게는 가지 치기 버튼 노출) |
| 비공개 부모 + 독자 | 본가지 최신 쪽 끝의 점선과 원래 시점의 stub으로 위치만 암시해요. 공개된 자식은 끊기지 않은 본가지에 연결된 채 정상 표시해요. |
| 부모 재발행 | 재조회하면 정상 가지와 열매로 복원해요. 자식 스냅샷과 부모 관계는 그대로 유지해요. |
| 발행 작품 없음 | `아직 발행된 작품이 없어요.`를 안내하고 비공개·초안 작품 목록·제목은 표시하지 않아요. |
| 작가 본인·검증된 관리자 | 전체 작품·가지를 표시해요. 발행했다가 비공개로 돌린 작품은 `비공개`, 한 번도 발행하지 않은 작품은 `초안` 칩을 붙여요. 독자 미리보기에서는 서버의 독자 투영만 사용해요. |
| 열매가 매우 많음(구간당 다수) | 겹침 방지를 위해 구간 안 순서대로 간격 배치, 스크롤. 성능 기준은 플랜에서 정함 |
| 로딩 / 실패 | 스켈레톤 트리 / `세계수를 불러오지 못했어요. 다시 시도해 주세요.` + `다시 불러오기` 버튼 |

### 접근성

- 공개 작품의 열매·가지는 버튼이며 `aria-label`에 이름·종류를 넣는다. 키보드는 Tab으로 이동하고 Enter로 선택한다. stub도 키보드 포커스 가능한 버튼으로 제공하되 `aria-label`은 정확히 `비공개된 본작 자리`이며 작품명·ID를 넣지 않는다.
- 시각 트리 외에 **목록 보기**(시간순 열매 목록)를 대체 수단으로 제공한다(구현은 플랜에서 결정, 화면 구성은 상세 패널 재사용).
- 색만으로 If/확장을 구분하지 않는다.
- 부러진 가지 끝의 점선·`부러진 가지` 라벨과 원래 시점의 stub 원·`비공개된 본작 자리` 라벨을 함께 쓴다. stub 목록 행은 `비공개된 본작 자리` 한 줄이며 부모 ID를 DOM에 넣지 않는다. stub 선택은 상세 패널(모바일 하단 시트)만 열고 정본 일반 안내만 표시한다. 작품 링크는 없다.

## 3. 연표 편집

- 상단: `세계관 연표` 제목, 설명, `+ 시대 구간 추가`, `연표 저장`. 가지별 연표 탭(본가지 / 가지 A …).
- 시대 구간은 열. 각 열 머리: 구간 이름, `{n}편` 칩, 연도 입력(선택), 설명.
- 작품 카드: 점 색, 제목, 종류 칩, `동시 진행` 칩(구간의 첫 작품은 표시 불가). 선택하면 하단 바에서 `← 이전 구간으로`, `다음 구간으로 →`, `구간 안에서 ↑`, `↓`, `앞 작품과 동시 진행 / 해제`.
- 이어받은 구간(분기 시점까지)은 점선·회색 잠금이며 수정 불가. 시도 시 토스트 `이어받은 구간은 수정할 수 없어요. 분기 이후 구간에서 편집해 주세요.`
- 잔가지의 독립 구간에는 `본가지 대응 메모(선택)` 입력이 있다(WTREE-02). 본가지 탭·이어받은 구간에는 없다.
- 드래그 이동은 구현 단계에서 지원하고 버튼 이동은 접근성 대체 수단으로 유지한다.

| 카피 | 문구 |
|------|------|
| 설명 | `시대 구간은 필수(이름·순서), 연도 숫자는 선택이에요. 작품(열매)을 구간에 배치하고, 같은 시기에 함께 벌어진 작품은 동시 진행으로 표시해요.` |
| 연도 placeholder | `연도(선택) 예: 세계력 120~180년` |
| 메모 placeholder | `예: 본가지 3기 후반에 해당` |
| 첫 작품 동시 진행 시도 | `구간의 첫 작품은 동시 진행으로 표시할 앞 작품이 없어요.` |
| 저장 완료 | `연표를 저장했어요. 세계수에 열매 위치가 반영돼요.` |
| 하단 안내 | `연표를 비교하고 싶을 때는 세계수 보기에서 가지의 분기점을 기준으로 이어서 봐요. 연표가 가지마다 독립이라 구간 이름이 같아도 가지끼리 시점이 일치한다고 보장하지 않아요.` |

## 4. 가지 치기 흐름 (5단계)

| 단계 | 내용 | 막는 조건 |
|------|------|-----------|
| 1. 세계수 시작 | 시작 위치(`내 작품의 세계관`만 활성), 자격 충족 현황, If / 확장 유형 선택, 복제 범위 안내 | 부모 독자 비노출(`parent_not_visible`)·발행 회차/설정 문서 기준 미충족·현황 로딩/조회 실패면 시작 불가 |
| 2. 설정 복제·수정 | 복제한 설정 문서 목록에서 수정·삭제·`+ 새 인물/장소/설정 문서`. 확장 가지는 기존 문서 수정·삭제 버튼 비활성 | — |

실제 문서 편집은 기존 스튜디오 에디터에서 이어지고 서버는 client counts/eligible 값을 믿지 않는다.

분기 이전 문서 잠금(WTREE-09)은 후속 범위다. 부모 비공개 시 자식 독자 진도를 기준으로 한다는 주석만 남기고 잠금 UI·진도 계산은 구현하지 않는다.

### 파괴적 액션

- **가지 확정**: 2단계의 `변경 내용 확인`으로 3단계에 진입해 경고를 읽고 `가지 확정`을 눌러 4단계로 간다(목업과 동일). 이때는 아직 서버에서 확정하지 않는다. 4단계 제목·시점 입력 후 `작품 만들기`를 누르면 서버가 자격·변경을 다시 검증하고 원자 확정한다. 별도 확인 다이얼로그는 두지 않는다(경고 박스가 확인 역할). `가지 확정` 표기는 하이픈·`하기` 없이 통일한다.
- **삭제**(WTREE-10): 하위 가지가 있는 가지·작품의 삭제 버튼은 비활성이며 툴팁 `하위 가지를 먼저 정리해 주세요.` 하위가 없으면 기존 삭제 확인 패턴을 따른다. 부모 비공개 전환은 기존 발행 설정에서 처리하며 하위에 전파되지 않는다. 이 화면에는 별도 공개 전환 액션을 만들지 않는다.

## 5. 세계관 설정·독자 미리보기

- 작품의 발행 상태만 독자 공개를 정한다. 발행 변경은 기존 작품/회차 발행 설정으로 연결한다.
- 세계관 설정에는 가지 치기 조건 요약·시작 버튼·연표 편집·스냅샷 알림·삭제 제한을 둔다.
- `작가 보기` / `독자 보기` 전환은 독자에게 어떻게 보이는지 확인하는 용도다. 관리자 전체 보기도 권한 검증 후 제공한다. 독자 보기 전환은 서버에 새 투영을 요청하고 응답 전에는 로딩을 표시한다.
- 독자에게 비공개 부모는 최신 쪽 끝의 부러진 가지와 원래 시점의 stub만 표시하고, 공개된 자식은 끊기지 않은 본가지에 연결해 정상 표시한다. stub에는 작품 상세 링크를 제공하지 않는다.
- 작가 전용 독자 미리보기 배너는 비공개 작품명을 포함할 수 있다(목업의 `작가 전용 안내`). 이 배너는 작가 전용이며 실제 독자 화면에는 절대 나오지 않는다. 모바일 목업의 상태 전환 컨트롤도 시안 확인용이며 실제 독자 화면에는 제공하지 않는다.
