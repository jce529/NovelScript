## Spacing / Typography

간격은 4의 배수만 쓴다: 4, 8, 12(카드 내부 gap 예외 없이 8·16 사용), 16, 24, 32, 48. 사용 토큰은 4·8·16·24·32·48이다.

| 용도 | 값 |
|------|----|
| 페이지 컨테이너 | `max-w-6xl`(1152px), 좌우 16px, 상단 24px, 하단 48px, 블록 간 24px |
| 데스크톱 그리드 | `repeat(auto-fill, minmax(180px, 1fr))`, gap 16px |
| 모바일 그리드(<640px) | `repeat(3, minmax(0, 1fr))`, 열 gap 8px, 행 gap 16px, 좌우 패딩 8px |
| 카드 내부 | 패딩 8px(데스크톱) / 0(모바일, 카드 테두리 없이 표지+텍스트), 요소 gap 8px(모바일 4px) |
| 칩·정렬 컨트롤 높이 | 최소 44px 히트 영역(시각 높이 36px 허용, 위아래 패딩으로 히트 영역 44px 확보) |

글자 크기는 정확히 4개: **11 / 12 / 14 / 18px**. 굵기는 정확히 2개: **400 / 600**. 본문 line-height 1.5, 제목 line-height 1.2.

| 토큰 | 용도 |
|------|------|
| 11px | 카드 라벨(NEW·완결), 모바일 카드 보조 줄(작가·장르·회차 수) |
| 12px | 카드 작가·장르·회차 수·가격 문구(데스크톱), 모바일 카드 제목, 정렬 안내 문구, 칩 |
| 14px | 카드 제목(데스크톱), 서브 행, 메인 탭, 버튼, 정렬/상태 셀렉트, 빈 상태 본문 |
| 18px | 페이지 제목(`무료연재`/`유료연재`), 빈 상태 제목 |

목업의 22px 제목·13px·15px·17px는 구현 시 위 토큰으로 정리한다. `eyebrow`(영문 `Free Series`)는 두지 않는다(한국어 UI 일관성, 토큰 절약).

## Color

60% dominant(`--background`), 30% secondary(카드·서브 행 배경·필터 칩 비활성), 10% accent(indigo primary).

accent 전용 요소(이 목록 밖에 쓰지 않는다):
1. 활성 메인 탭 밑줄·글자, 활성 서브 행 항목 글자
2. 포커스 링
3. 가격 문구 `N화부터 유료`/`회차당 N토큰~`의 글자색(`text-primary`)
4. 활성 장르 칩은 accent가 아니라 `--foreground` 배경 반전(목업과 동일)으로 구분한다

라벨 색(색만으로 구분하지 않고 텍스트 병기):
- `NEW`: `--primary` 배경 + `--primary-foreground` 글자
- `완결`: `--foreground` 배경 + `--background` 글자(표지 위 가독성 확보). 표지 위 라벨은 반투명 없이 불투명 배경으로 4.5:1 이상 대비
- 두 라벨이 동시에 해당하면 `완결`만 표시한다(3절 라벨 규칙)

destructive 색은 이 화면에 쓰지 않는다(파괴적 액션 없음). 오류 문구는 `--foreground` + 보더로 처리한다. 다크 모드는 토큰이 자동 반전되며 라벨 대비만 확인한다.

## 1. 헤더 (2단 노출 요건)

- 연재 목록 경로(`/series/free`, `/series/paid`)는 `getHeaderVariant`에서 **`reader`(2단: 메인 탭 + 서브 행)** 로 분류한다. 현재는 `compact`(1단)이라 수정이 필요하다(plan 포함).
- 활성 메인 탭은 현재 `useState('free')` 고정이 아니라 **pathname에서 도출**한다(`/series/free`→`무료연재`, `/series/paid`→`유료연재`). 서브 행 활성은 `sub` 쿼리에서 도출한다.
- 서브 행 링크(`navigation.ts`의 `href: null` 8개 연결):

| 탭 | 항목 | href |
|----|------|------|
| 무료연재 | 전체 / 신작 / 인기 / 완결 | `/series/free` / `?sub=new` / `?sub=popular` / `?sub=completed` |
| 유료연재 | 전체 / 신작 / 인기 / 완결 | `/series/paid` / `?sub=new` / `?sub=popular` / `?sub=completed` |

- 서브 행 이동은 `genre` 쿼리를 유지하고 `page`·`sort`를 제거한다. 메인 탭(무료↔유료) 이동은 `sub=all`로 시작하고 `genre`는 유지하지 않는다(탭마다 작품 집합이 다르므로 `전체`).
- 서브 행 항목은 `Link`(`aria-current="page"`로 활성 표시), 최소 높이 44px, 가로 스크롤 가능(scrollbar 숨김, 포커스 시 `scrollIntoView`). `href: null`이던 "준비 중" 스타일은 이 8개에서 사라진다.
- 헤더는 sticky 유지. 서브 행은 모바일에서도 보인다(가로 스크롤).

## 2. 목록 화면 구성 (위→아래)

1. **제목 블록**: `h1` 18px/600(`무료연재` 또는 `유료연재`) + 12px 설명.
2. **필터 바**(`ListFilterBar`): 좌측 장르 칩 가로 스크롤 줄, 우측 `정렬` 셀렉트 + `상태` 셀렉트. 모바일은 두 줄(칩 줄 / 셀렉트 줄)로 접힌다.
3. **정렬 안내 한 줄**(12px, `--muted-foreground`): 현재 정렬 설명(카피 표).
4. **그리드**(`WorkGrid`): `SeriesCard` N개.
5. **`더보기` 버튼**(그리드 아래 중앙): 남은 작품이 있을 때만 노출.
6. 결과 건수는 `aria-live="polite"` 영역(시각 숨김 가능)으로 `작품 {n}개`를 알린다.

### 장르 칩 (`genre`)
- 칩: `전체` + `lib/works/genres.ts`의 `GENRES`(기존 홈 `FeedFilters`와 같은 소스, 목업의 7개를 하드코딩하지 않는다). 목업의 `태그검색` 칩은 **이 phase에서 만들지 않는다**(검색은 별도 화면).
- 단일 선택. 선택 시 `genre` 쿼리 설정, `page` 제거. `전체`는 `genre` 쿼리 제거.
- 칩은 `button`(`aria-pressed`), 가로 스크롤 영역은 키보드 Tab/화살표 이동 가능. 활성 칩 `--foreground` 반전.

### 정렬 셀렉트 (`sort`)
| 옵션 | `sort` 값 | 기본이 되는 서브 행 |
|------|-----------|---------------------|
| 업데이트순 | `updated` | 전체, 완결 |
| 연재 시작일순 | `started` | 신작 |
| 인기순 | `popular` | 인기 |

- 서브 행이 기본 정렬을 정하고, 사용자가 셀렉트로 바꾸면 `sort` 쿼리로 덮어쓴다. 서브 행 기본값과 같으면 `sort`는 URL에 쓰지 않는다.
- `신작` 서브 행은 정렬 셀렉트가 `연재 시작일순`으로 보인다. 신작에서 정렬을 바꿔도 목록 필터(신작=연재 시작 14일 이내가 아니라 **연재 시작일 최신순 전체**, D-05)는 유지된다.
- 정렬 셀렉트 라벨: `aria-label="정렬"`.

### 상태 셀렉트
| 옵션 | 동작 |
|------|------|
| 연재 전체 | `sub=completed`이면 `sub=all`로 되돌림(그 외 서브 행에서는 변화 없음) |
| 완결만 | `sub=completed`로 이동(서브 행 `완결`과 같은 상태) |

- 상태 셀렉트는 서브 행 `완결`과 **항상 동기화**된다(독립 쿼리 키를 만들지 않는다). `aria-label="상태"`.
- `완결` 서브 행 + 정렬 `연재 시작일순`/`인기순` 조합은 허용한다.

## 3. 카드 구조 (`SeriesCard`)

`<Link href="/works/{id}">` 전체가 클릭 영역이며 카드 하나가 탭 정지 하나다.

```
[표지 3:4]   좌상단: 라벨(NEW | 완결, 21 전용 `badge`) — `overlay`가 있으면 overlay가 대신 차지
             우상단: `corner` 슬롯 (22: 새 회차 배지)
             좌상단 `overlay` 슬롯 (23: 순위 숫자)
제목 (2줄 clamp)
작가 필명
장르 Badge · {n}화 Badge
가격 문구 (21 전용, footer 슬롯에도 대체 가능)
footer 슬롯 (22: 진도 바 등)
```

- 표지 없음: 회색 배경 + `표지 없음` 12px(`FeedCard`와 동일 처리). 이미지 `alt`는 작품 제목, `loading="lazy"`, 첫 줄(상위 6개)은 eager.
- 작가: `profiles.pen_name` 우선, 없으면 `작가`(빈 이름 노출 금지). 한 줄 truncate.
- `{n}화` = **공개·미삭제 회차 수**. 회차 0개 작품은 목록에 나오지 않는다(연재 시작일이 없으므로).
- 모바일(3열): 카드 테두리·배경 없음, 표지 + 제목(12px/600, 2줄) + 보조 한 줄(11px: `장르 · n화`, 작가는 11px 한 줄) + 가격 문구(11px). Badge 칩은 쓰지 않고 텍스트로 이어 쓴다. 넘치면 말줄임.
- 호버(데스크톱): 배경 5% 어둡게(`FeedCard`와 같은 `color-mix`), 모바일은 `:active`만.

### 라벨 규칙 (표지 좌상단, 최대 1개)

| 라벨 | 노출 조건 | 우선순위 |
|------|-----------|----------|
| `완결` | `serial_status = completed` | 1 |
| `NEW` | 연재 시작일(첫 공개 회차 `published_at`)이 현재 시각 기준 **14일 이내** (상수 `NEW_BADGE_DAYS = 14` 한 곳) | 2 |

- 둘 다 해당하면 `완결`만 보인다. 둘 다 아니면 라벨 없음.
- 라벨에는 `aria-label` 없이 글자 그대로 읽히게 하고, 표지 `alt`에는 넣지 않는다. 카드 `Link`의 접근 가능한 이름에 `, 완결`/`, 신작`을 덧붙이지 않는다(텍스트 라벨이 이미 DOM에 있음).
- 연재 시작일은 작품 `created_at`이 아니다(D-05).

### 가격 문구 규칙 (3종, 무료/유료 탭 공통 함수 하나)

입력: 작품의 공개·미삭제 회차를 `episode_no` 오름차순으로 본 `price_tier` 목록.

| 문구 | 노출 조건 | 값 계산 |
|------|-----------|---------|
| `무료` | 공개 회차 중 `price_tier`가 있는 것이 없음 | — |
| `{N}화부터 유료` | 유료 회차가 있고 **첫 회차(1화)가 무료**(앞부분 무료 후 유료 전환) | N = 가장 앞선 유료 회차의 순번(공개 회차 기준 1부터) |
| `회차당 {N}토큰~` | 유료 회차가 있고 **1화부터 유료**(무료 회차가 하나도 없음) | N = 공개 유료 회차 중 최저 `price_tier`(10/30/50/100 중) |

- 무료 탭에는 `무료`만, 유료 탭에는 나머지 두 종만 나온다(작품은 한 탭에 한 번, D-02). 목업의 "회차 수 20 초과면 회차당 3토큰~" 샘플 규칙은 **폐기**한다.
- 규칙 모호 방지: `N화부터 유료`에서 N은 항상 2 이상이다.
- 가격 문구 텍스트는 12px/600, 무료는 `--muted-foreground`, 유료 두 종은 `text-primary`.
- 가격 숫자는 `formatKoreanCount`가 아닌 단순 정수(토큰 단가는 천 단위 구분 없음)로 표기한다.

## 4. 더보기 · URL 쿼리 규칙

> `신작`(`sub=new`)은 `sort=started`와 같은 순서지만 **의도된 별칭**이다(백로그 19번이 서브 행으로 요구). 서브 행 `신작`에서는 `sort`를 URL에 쓰지 않는다.
> `더보기` 버튼은 글자 `더보기`를 유지하고 `aria-label="작품 더 보기"`로 읽힌다. 첫 화면 시각 앵커는 첫 줄 카드 그리드다. 44px는 간격 토큰이 아니라 터치 히트 영역 예외다(시각 높이 36px 허용).

| 쿼리 | 값 | 기본(생략 시) | 비고 |
|------|----|---------------|------|
| `sub` | `new` \| `popular` \| `completed` | 전체 | `all`은 URL에 쓰지 않는다 |
| `genre` | `GENRES` 중 하나 | 전체 | 알 수 없는 값은 무시하고 전체로 처리 |
| `sort` | `updated` \| `started` \| `popular` | 서브 행 기본 정렬 | 기본과 같으면 URL에 쓰지 않음 |
| `page` | 1 이상의 정수 | 1 | 1이면 URL에 쓰지 않음 |

- `page`는 **누적 페이지 수**다: `page=3`이면 처음부터 72개(24×3)를 한 번에 서버 렌더한다(D-03). `더보기` 클릭 → `page+1` URL로 `router.push(..., { scroll: false })` 후 새 24개가 이어 붙는다(앞 항목 유지·스크롤 위치 유지). 뒤로 가기로 이전 `page`로 복원된다.
- 필터·정렬·서브 행 변경은 `page`를 제거해 첫 24개부터 시작한다.
- 잘못된 `page`(0, 음수, NaN)는 1로, 결과 수를 넘으면 마지막 가능 페이지로 보정한다(404 없음).
- `더보기`는 남은 작품이 있을 때만 노출한다(`전체 건수 > 현재 표시 수`). 마지막까지 보면 버튼 대신 텍스트를 쓰지 않고 그냥 사라진다.
- `더보기` 클릭 중에는 버튼이 `불러오는 중…` + `disabled`. 중복 클릭 방지.
- `searchParams`는 `Promise`이므로 `await`로 읽는다(`node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/page.md`).
- 접근성: 새 항목 추가 후 포커스는 `더보기` 버튼에 남기지 않고 **새로 추가된 첫 카드**로 이동한다(`tabIndex=-1` + `focus()`), `aria-live` 영역에 `작품 {n}개 더 불러왔어요`를 알린다.

## 8. 접근성

- 모든 인터랙티브 요소(서브 행, 메인 탭, 장르 칩, 셀렉트, `더보기`, `필터 초기화`, 상태 토글 버튼) 최소 **44×44px** 히트 영역. 모바일 3열 카드 전체가 단일 탭 대상이다.
- 포커스: `focus-visible` 링 2px indigo(`--ring`), 칩/카드 모두 `outline-offset: 2px`. 카드 `Link` 전체에 링이 보여야 하며 `overflow:hidden`에 잘리지 않게 링은 카드 바깥쪽에 둔다.
- 서브 행/메인 탭은 `<nav aria-label>`(`연재 구분`, `서브 구분`), 활성은 `aria-current="page"`.
- `h1` 하나, 카드 제목은 `h3`(목록 의미: `ul`/`li`로 그리드 구성).
- 색만으로 상태를 전달하지 않는다(NEW/완결/가격은 모두 텍스트).
- 로딩 `aria-busy`, 오류는 `role="alert"`, 결과 건수·더보기 알림은 `aria-live="polite"`.
- `prefers-reduced-motion`에서 호버 전환·스켈레톤 pulse를 끈다.
