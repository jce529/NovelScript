## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 아이콘-텍스트 간격, 상태 문구 위 여백 |
| sm | 8px | 현황 칸 내부 라벨-숫자 간격, 카드 그리드 gap(모바일) |
| md | 16px | 카드 내부 padding, 가이드 단계 행 padding, 카드 그리드 gap(데스크톱) |
| lg | 24px | 섹션 간격(헤더 / 현황 / 가이드 / 작업 화면), 페이지 좌우 padding |
| xl | 32px | 빈 상태 가이드 내부 상하 padding |
| 2xl | 48px | 사용 안 함(예약) |
| 3xl | 64px | 사용 안 함(예약) |

Exceptions: 모바일 터치 대상(작업 화면 행, 단계 알약 버튼, 링크)은 높이 최소 44px(`min-h-11`). 이 값은 4의 배수라 예외가 아니라 하한이다. 진행 막대 두께 8px.

## Typography

크기 4종, 굵기 2종.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (시놉시스, 단계 설명, 카드 상태 문구) | 14px | 400 | 1.5 |
| Label (현황 라벨, 진행 "3 / 5 완료", 보조 링크) | 12px | 400 | 1.5 |
| Heading (섹션 제목 "작업 화면"/"연재 시작 가이드", 카드 제목, 단계 제목, 현황 숫자) | 16px | 600 | 1.2 |
| Display (작품 제목 h1) | 22px | 600 | 1.2 |

현황 숫자는 Heading(16px/600)을 쓰고 라벨은 12px/400이다. 시안의 11·13·15px는 가장 가까운 선언 크기(12·14·16)로 흡수한다.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` 흰색 / 작업 영역 배경 | 홈 본문 배경 (시안 #f7f7f9 대신 기존 앱 배경 토큰 사용) |
| Secondary (30%) | `--card` 흰색 + `--border` (oklch 0.922) 테두리, `--muted` 회색 | 현황 칸, 작업 화면 카드, 가이드 패널, 진행 막대 트랙 |
| Accent (10%) | `--primary` indigo-600 (hover 시 indigo-700) | 아래 목록만 |
| Destructive | `--destructive` | 이번 화면에서는 사용 안 함 |

본문 텍스트는 `--foreground`, 보조 텍스트는 `--muted-foreground`(시안 #52525b 대응). 심사 "대기 중" 상태 문구만 시안의 amber(#b45309, Tailwind `text-amber-700`)를 쓰는 의미색 예외다.

Accent reserved for:
1. 가이드의 "지금 할 단계" 강조(왼쪽 번호/체크 원, 단계 제목 옆 표시)와 그 단계의 주 버튼(`설정 추가`, `열기 →`)
2. 가이드 진행 막대 채움 영역
3. 완료 단계의 체크 아이콘
4. 카드/행 hover 시 제목 색, 키보드 포커스 링(`--ring`)

현황 4칸, 일반 카드 아이콘은 중립 회색을 쓰고 accent를 쓰지 않는다.

## Layout and Interaction Contract

### 구성 순서 (데스크톱, 시안 D·C·B)
오른쪽 본문 영역(17-07 왼쪽 트리 사이드바는 그대로, D-06/D-07). 최대 폭 960px, 본문 padding 24px, 섹션 간격 24px.

1. **헤더**: `← 작품 목록` 링크(12px, `/studio`), 작품 제목 h1(22px/600), 시놉시스(14px, muted, 최대 2줄 말줄임). 시놉시스가 없으면 그 자리를 비운다(안내 문구·링크 없음, 2026-11-01 결정).
2. **현황 4칸 (D-01)**: 전체 회차 · 공개 · 미공개 · 심사 상태. 데스크톱 4열 1행, 칸은 `rounded-lg border bg-card p-4`, 라벨 12px 위 / 값 16px/600 아래. 심사 칸의 값은 상태 텍스트("심사 대기 중" 등). 독자 지표·토큰·설정 문서 수는 넣지 않는다(D-02).
3. **연재 시작 가이드 (D-03)**: 아직 "끝나지 않은" 동안만 표시. 5단계 세로 목록 + 상단 진행 막대와 "N / 5 완료" 라벨.
4. **작업 화면 바로가기 5개 (D-04)**: 가이드 완료 후 표시. 데스크톱 3열 그리드(5개라 둘째 줄은 2개)(gap 16px). 사이드바가 좁아 카드 폭이 200px 미만이면 2열로 줄인다(컨테이너 쿼리 또는 `grid-cols-[repeat(auto-fill,minmax(200px,1fr))]`, 최대 3열).

### 가이드 5단계 (D-03)
| # | 제목 | 보조 문구 | 완료 판정(제안) | 이동 |
|---|------|-----------|-----------------|------|
| 1 | 작품 만들기 | 없음 | 항상 완료 | 없음 |
| 2 | 세계관 설정 문서 추가 | 인물·장소를 적어 두면 AI가 설정에 맞게 도와줘요 | `getWorkKbNodes` 결과 1개 이상 | `설정 추가` 버튼 -> 세계관 설정(`/studio/{id}/world`) |
| 3 | 첫 회차 쓰기 | 없음 | `listChapters` 1개 이상 | 회차 목록으로 이동 버튼 |
| 4 | 첫 회차 공개하기 | 없음 | `is_published`인 회차 1개 이상 | `열기 →` -> 회차 목록 |
| 5 | 세계관 공개 심사 요청 (선택) | 없음 | 심사 상태가 요청 이력 있음(대기/승인/반려 등) | 심사 요청 카드와 같은 동작 |

- 단계 상태 3종: 완료(체크 아이콘 + 제목 muted), 지금 할 단계(첫 미완료 필수 단계. accent 강조 + 주 버튼 노출), 대기(회색 번호, 버튼 없음). 5단계 "(선택)"은 제목에 붙은 라벨이고 "지금 할 단계"가 될 수 있다.
- 시안 C처럼 중간 단계가 "열기 →" 링크로 보이는 것은 "지금 할 단계"일 때만이다. 5단계가 "대기 중" 상태면 단계 오른쪽에 amber "대기 중" 텍스트.
- 진행 막대: `완료 수 / 5`, 8px 높이, 트랙 `--muted`, 채움 `--primary`. `role="progressbar"` + `aria-valuenow/min/max`.
- **가이드 종료 기준(제안)**: 필수 4단계(1~4) 완료 시 가이드 종료. 5단계(선택)는 종료 조건이 아니다. 종료 후 가이드는 사라지고(접힘 아님) 바로가기 5개 카드가 같은 자리에 나온다. 사용자가 되돌릴 수 있는 토글은 두지 않는다.

### 빈 상태 (D-08, D-09, 시안 G)
- 회차 0개: 현황 4칸 숨김. 가이드만 크게(패널 padding 32px, 단계 행 padding 16px) 보여 주고 "지금 할 단계"(보통 2단계 `설정 추가` 버튼)를 강조.
- 가이드가 끝나기 전에는 작업 화면 카드를 가이드 아래에 접어 둔다: 접힘 헤더 "작업 화면"(`<details>` 또는 shadcn 없이 `button aria-expanded`) 기본 닫힘. 가이드 단계 1~4 진행 중에도 동일(현황 4칸은 회차 1개 이상이면 표시).
- 사이드바 트리 빈 폴더(D-10): "아직 회차가 없어요", "아직 설정 문서가 없어요"를 해당 폴더 아래 12px muted로 표시(`sidebar-groups.tsx`/`kb-tree.tsx` 수정 범위, 트리 구조는 불변).

### 바로가기 카드 5개 (D-04, 시안 B·D, 작품 설정 카드 제외)
순서와 상태 문구(회색 12px 아래줄):

| 카드 | 상태 문구 | 이동 |
|------|-----------|------|
| 회차 목록 | `회차 {n}개 · 새 회차 쓰기` (0개면 `아직 회차가 없어요`) | `/studio/{id}/chapters` |
| 세계관 설정 | 설정 문서와 공개 범위 | `/studio/{id}/world` |
| 타임라인 | 사건 순서 정리 | `/studio/{id}/world/timeline` |
| 가지 치기 | 이 세계관에서 새 작품 | `/studio/{id}/world#world-branching` |
| 심사 요청 | `대기 중 · {n}일 전 요청` / 요청 전엔 `세계관 공개 심사 요청` / 기타 상태는 상태 텍스트 | 심사 요청 영역(아래 가정 A3) |

- 카드 전체가 하나의 `Link`(키보드 포커스·hover 가능). 카드: `rounded-lg border bg-card p-4`, 제목 16px/600 + 12px 상태 문구, 왼쪽 위 lucide 아이콘 20px 회색(회차 `BookOpen`, 세계관 `Globe`, 타임라인 `Clock`, 가지 치기 `GitBranch`, 심사 `ShieldCheck`). hover: 제목 indigo-700, 테두리 진하게. 개별 회차·설정 문서 링크는 두지 않는다(D-06).
- 상태 지시 추천("지금 할 일")은 없다(D-05).

### 모바일 (D-11, D-12, 시안 H·I)
- 하단 탭 `설정집·회차` / `집필` / `AI` 구조 불변. 홈은 `집필` 탭 안에 표시(`StudioWorkspace`의 write 패널 안에서 홈 렌더).
- 현황은 2x2 그리드(gap 8px). 작업 화면은 세로 목록 행(`min-h-11`, 행 padding 16px, 오른쪽 `›` ChevronRight, 행 사이 구분선). 행에는 제목 + 12px 상태 문구.
- 가이드 단계 버튼은 전체 폭 알약(`w-full rounded-full min-h-11`, indigo 배경 흰 글씨). 지금 할 단계에만 버튼을 둔다.
- 빈 상태(I): 헤더 + 가이드 전체 폭, 작업 화면은 접힘.

### 상태
| 상태 | 처리 |
|------|------|
| 로딩 | 서버 컴포넌트 렌더. 클라이언트 전환 없이 `loading.tsx` 없이도 되게 데이터는 서버에서 `Promise.all`로 한 번에 읽는다 |
| 작품 없음/접근 불가 | 기존 동작 유지(제목 비어 보이지 않게 `작품을 찾을 수 없어요` + `← 작품 목록` 링크) |
| 심사 상태 조회 실패 | 현황 심사 칸 값 `확인 못 했어요`, 심사 카드는 상태 문구 없이 표시. 나머지 화면은 정상 |
| 회차 0개 | 위 빈 상태 |

### 접근성
- 현황 4칸은 `dl`(라벨 `dt`, 값 `dd`) 또는 `aria-label`로 "라벨 값"을 읽게 한다. 섹션은 `h2`로 구분(`작업 화면`, `연재 시작 가이드`). 가이드는 `ol`. 완료 단계는 시각 외에 "완료" 스크린리더 텍스트 포함. 모든 대화형 요소 포커스 링 `--ring`. 대비는 muted-foreground 12px 텍스트도 4.5:1 이상 유지(흰 배경 기준).

## 제안 요구사항 (REQUIREMENTS.md 미수정, 승인 후 반영)

- WORKHOME-01: 작품 홈은 전체 회차·공개·미공개·심사 상태 4칸 현황을 기존 데이터(`listChapters`, 심사 패널 상태)만으로 보여 준다 (D-01, D-02).
- WORKHOME-02: 첫 연재를 마칠 때까지 5단계 연재 시작 가이드(체크리스트 + 진행 막대)를 보여 주고, 필수 4단계 완료 시 가이드가 사라진다 (D-03, D-05).
- WORKHOME-03: 가이드 종료 후 회차 목록·세계관 설정·타임라인·가지 치기·심사 요청 고정 바로가기 5개 카드를 상태 문구와 함께 보여 준다 (D-04, D-06).
- WORKHOME-04: 홈은 개요, 17-07 왼쪽 트리는 탐색 역할로 유지하며 트리 구조는 바꾸지 않는다 (D-06, D-07).
- WORKHOME-05: 회차 0개 새 작품은 현황을 숨기고 가이드만 크게 보여 주며 작업 화면 카드는 접어 둔다. 트리 빈 폴더 안내를 둔다 (D-08, D-09, D-10).
- WORKHOME-06: 모바일은 기존 하단 탭의 `집필` 탭에 홈을 넣고 현황 2x2, 작업 화면 세로 목록(행 44px 이상), 가이드 버튼 전체 폭 알약으로 배치한다 (D-11, D-12).
- WORKHOME-07: UI-SPEC과 승인 목업을 근거로 실제 화면을 구현하고, 시안에 없는 UI는 목업을 먼저 보여 준다 (D-13, D-14).

## Assumptions (CONTEXT.md가 열어 둔 부분을 이 spec이 정한 값)

- A1. 가이드 종료 기준은 필수 4단계 완료이며, 종료 후 가이드는 사라진다(접힘 아님). 시안 C 주석 "접히거나 사라진다" 중 단순한 쪽 선택. 5단계(선택)는 미완료여도 종료.

- **바로가기 카드 4개**: 회차 목록 · 세계관 설정 · 타임라인 · 가지 치기.
