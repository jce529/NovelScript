# BUG-03: 템플릿 카테고리 폴더 구조 — 남은 검증

원래 증상은 "저장 모달의 템플릿 목록이 카테고리로 걸러지지 않아 다른 카테고리 템플릿을 고르면 재생성이 실패한다"였다. 폴더 구조(`template/인물·장소·사건·세력·아이템`), `0012` 마이그레이션, 서버 규칙, KB 트리 UI, 작품/계정/기본 그룹 표시는 수정·검증이 끝나 `.planning/fixed/15-03 템플릿 카테고리 폴더 구조 수정.md`로 옮겼다.

## 남은 것 (브라우저 UAT에서 아직 확인하지 못함)

1. **목록 전 항목 재생성**: 인물 문서 저장 모달의 "템플릿 변경" 목록에 보이는 모든 항목(작품/계정/기본)으로 "다시 생성하기"가 실패하지 않는지. 2026-09-29 UAT 중 Gemini 503이 이어져 판정하지 못했다. BUG-04(재생성 이름 유지) UAT와 같은 흐름이라 함께 확인한다.
2. **AI 템플릿 추천(2-5)**: 저장 모달의 추천 템플릿이 인물용 후보 안에서 선택되는지, 후보가 캐노니컬 하나뿐일 때도 오류 없이 기본값으로 떨어지는지.
3. **미분류 표시**: 루트 직속에 남은 커스텀 이름 템플릿 파일에 "미분류" 표시와 툴팁이 보이는지. 이 테스트 DB의 UAT 계정 작품에는 루트 직속 파일이 없어 관찰하지 못했다(다른 테스트 계정에는 38개 있음).
4. **이동 후 목록 반영**: 템플릿을 다른 카테고리로 옮긴 뒤 그 카테고리 문서의 템플릿 목록에 나타나는지(인물용 목록에서 빠지는 것은 확인함).
5. **`0012` 파일 이동 경로**: 이 테스트 DB에는 이름=카테고리 평면 시드 파일이 없어 이동·내용 보존(B4)이 검사 대상 없이 통과했다. 평면 구조 데이터가 있는 DB가 생기면 다시 본다. (단위/통합 테스트 `tests/studio/schema-smoke.test.ts`가 이 경로를 다루지만, 적용 후 재실행은 아직 안 했다.)

## 참고 관찰 (판정 외, 필요하면 별도 버그로)

- 저장 모달의 템플릿 목록은 채팅에서 모달이 로드된 뒤 추가된 템플릿을 새로고침 전까지 반영하지 않는다(새로고침하면 채팅이 사라진다).
- 카테고리 폴더 안의 시드 파일에도 "카테고리 폴더로 이동" 버튼이 있고 현재 폴더가 기본 선택이라 아무 일도 일어나지 않는다.
- 템플릿 이름 다이얼로그에서 Enter가 제출되지 않는다(버튼 클릭은 정상).
- 셀렉트 항목의 "(기본)"이 체크 표시에 겹쳐 잘려 보인다.

## 검증 기준

- 저장 모달과 문서 만들기 다이얼로그에서 목록의 모든 항목으로 재생성/생성이 성공한다.
- 나머지 항목은 위 목록의 관찰이 브라우저에서 확인되면 이 문서를 `fixed/`로 옮기고 삭제한다.
