## 1. BUG-02 — 저장 모달 셀렉트가 UUID 대신 이름 표시
1. [ ] AI 채팅에서 "새 인물 ○○에 대한 인물 설정 문서를 만들어줘" 전송.
2. [ ] 응답의 "문서로 저장하기" 클릭 → 모달을 연다.
3. [ ] "저장 폴더 변경"과 "템플릿 변경" 트리거가 UUID가 아니라 이름("인물 (최상위)", "…(기본)")을 표시한다. (목록을 열기 전 상태에서)
4. [ ] 폴더를 서브 폴더로 바꾸면 트리거가 새 폴더 이름을 표시한다.
5. [ ] 템플릿을 바꾸면 트리거가 새 템플릿 이름을 표시한다.

## 2. BUG-03 — 템플릿 카테고리 폴더 구조
### 2-1. KB 트리 구조 (작품/계정 각각)
- [ ] 작품의 `template` 폴더 아래에 인물/장소/사건/세력/아이템 폴더 5개가 있다. 각 폴더 안에 시드 파일(이름=카테고리)이 있다.
- [ ] 계정 공유 영역(계정 템플릿)도 같은 구조다.
- [ ] 카테고리 폴더는 이름 변경/삭제 버튼이 없다(잠김).
- [ ] `template` 루트와 카테고리 폴더에는 "새 폴더 만들기" 버튼이 없다.
- [ ] `template` 루트에는 "하위 문서 추가"도 없다.
- [ ] 카테고리 폴더에는 "하위 문서 추가"가 있다.

### 2-2. 카테고리 지정 UI
- [ ] 카테고리 폴더(예: 인물)에서 "하위 문서 추가" → 제목이 "새 템플릿 만들기", 템플릿 선택 셀렉트가 없다. 이름 입력 후 생성.
- [ ] 생성된 파일 내용이 해당 카테고리의 기본 템플릿 원문이다(제목 자리표시자 `<% tp.file.title %>` 그대로).
- [ ] 같은 이름으로 다시 만들면 이름 충돌 안내가 뜬다.
- [ ] (기존 데이터에 커스텀 이름 템플릿이 있다면) 루트에 남은 파일에 "미분류" 표시와 툴팁이 보인다.
- [ ] 템플릿 파일의 "카테고리 폴더로 이동" → 셀렉트가 UUID가 아니라 카테고리 이름을 표시하고, 이동하면 그 폴더 아래로 옮겨진다.
- [ ] 이동 후 그 카테고리 문서의 템플릿 목록에 나타난다.

### 2-3. 저장 모달의 템플릿 목록 (핵심 회귀)
- [ ] "인물" 문서 저장 모달의 "템플릿 변경" 목록에 **인물용 템플릿만** 있다(장소/사건/세력/아이템 템플릿 없음).
- [ ] 목록이 `작품 템플릿` / `계정 템플릿` / `기본 템플릿` 그룹으로 나뉜다. 같은 이름이 작품과 계정에 있으면 각 그룹에 따로 보인다.
- [ ] 목록의 모든 항목을 골라 "다시 생성하기"를 해도 실패하지 않는다(이전엔 다른 카테고리 템플릿 선택 시 실패).
- [ ] "(기본)" 표기가 작품 > 계정 > 기본 우선순위의 기본값에 붙는다.

### 2-4. 문서 만들기 다이얼로그
- [ ] 인물 폴더의 "하위 문서 추가" → 템플릿 선택이 3그룹으로 나뉘고 인물용만 보인다.
- [ ] 선택한 템플릿 내용으로 문서가 생성된다(제목 치환 적용).

### 2-5. AI 추천
- [ ] 저장 모달의 추천 템플릿이 인물용 후보 중에서 선택된다(후보가 하나뿐일 때도 오류 없이 기본값).

## 3. BUG-04 — 재생성 시 문서 이름 유지
1. [ ] "새 인물 강진욱에 대한 인물 설정 문서를 만들어줘"로 제안 생성(이름 "강진욱").
2. [ ] 저장 모달에서 추천값과 다른 템플릿("기본 인물 템플릿" 등)으로 바꾸고 "다시 생성하기" → 저장.
3. [ ] 저장된 문서 이름이 "강진욱"이고 본문 첫 제목도 "강진욱"을 포함한다.
4. [ ] 원본에 `[[링크]]`가 있는 제안으로 반복: 재생성 결과에 원본에 없던 새 링크 대상이 없다(있으면 "문서를 다시 생성하지 못했어요" 안내).
5. [ ] 원래 모델(lite 아님)로 여러 번 반복해 이름이 바뀌는 사례가 재현되는지 기록한다(문서의 "미확인" 항목).
6. [ ] 모델이 이름을 바꾼 응답을 내면 실패 안내가 뜨고 잘못된 이름으로 저장되지 않는다.
