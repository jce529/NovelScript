    **lib/ai/decision/shadow.ts** (`import 'server-only'`):
    ```ts
    export interface ShadowTrigger { ownerId: string; workId: string; requestKey: string; requestLength: number; hasChapterContext: boolean; mentionedFactCount: number; }
    export interface ShadowDeps {
      client: DecisionClient; admin: SupabaseClient; rng: () => number; now: () => Date;
      sampleRate: number; dailyMax: number; modelVersion: string;
    }
    export const ESTIMATED_COST_PER_CALL_USD = 0.0005; // 벤더 단가 확정 시 갱신 (RESEARCH.md)
    export const SHADOW_MAX_CONCURRENCY = 2;
    export function bucketFor(t: Pick<ShadowTrigger, 'requestLength' | 'hasChapterContext' | 'mentionedFactCount'>): ShadowBucket;
    export function pickScenario(bucket: ShadowBucket, seedKey: string): ShadowScenario; // 문자열 해시 % bucket 내 개수
    export async function runShadowPlan(deps: ShadowDeps, trigger: ShadowTrigger): Promise<{ skipped?: 'not_sampled' | 'daily_budget' | 'circuit_open' | 'concurrency' }>;
    ```
    runShadowPlan 순서 (전체 try/catch — 절대 reject하지 않음, 실패 시 `console.error('[ai] shadow plan failed', { stage: 'shadow' })`만):
    1. `if (deps.rng() >= clamp(deps.sampleRate, 0, 0.2)) return { skipped: 'not_sampled' }`
    2. 모듈 변수 `inFlight >= SHADOW_MAX_CONCURRENCY` → concurrency. 이후 `inFlight++`, finally `inFlight--`.
    3. 오늘(UTC 00:00 이후) `ai_doc_plan_shadow_log` count(`select('id', { count: 'exact', head: true })`) ≥ dailyMax → daily_budget. 조회 error → skip(daily_budget).
    4. 최근 10분 최신 20행 status 조회, error ≥ 10 → circuit_open.
    5. `scenario = pickScenario(bucketFor(trigger), trigger.requestKey)`; `task = await planTaskAndCategory(deps.client, scenario.state)`.
    6. document이고 카테고리가 결정되면 `ft = await planFolderAndTemplateFromCandidates(deps.client, { state: scenario.state, folders: scenario.folders, templates: scenario.templates })`.
    7. `calls = [...task.calls, ...(ft?.calls ?? [])]`; `status = calls.some(c => !c.ok) ? 'error' : 'ok'`; insert:
       `{ owner_id, work_id, scenario_id: scenario.id, bucket, model_version: deps.modelVersion, status, error_kind: calls.find(c => !c.ok)?.errorKind ?? null, task_decision: task.kind === 'unavailable' ? null : task.kind, task_confidence, category_decision, category_confidence, expected_task, expected_category, task_correct: task.kind === 'unavailable' ? null : (task.kind === scenario.expectedTask && (task.kind !== 'document' || task.category === scenario.expectedCategory)), folder_fallback: ft?.folderFallback ?? null, template_fallback: ft?.templateFallback ?? null, call_count: calls.length, latency_ms: calls.reduce((a, c) => a + c.latencyMs, 0), estimated_cost_usd: calls.length * ESTIMATED_COST_PER_CALL_USD, applied: false }`
    8. `if (deps.rng() < 0.01) await deps.admin.rpc('purge_ai_doc_plan_logs', { p_retention_days: 90 })`.
