| Option | Description | Selected |

| Gemini Flash-Lite (검증 버전) | 기존 Gemini 계열 최저렴·저지연 모델 재사용 | |

| 별도 저비용 분류 모델(타 벤더) | Jev 전용 신규 벤더 온보딩 | |

**사용자 응답:** "내가 Jev모델에 대해서 최근에 접해서 기존의 LLM모델로 구동할 수 있는거야?" — 질문으로 되돌아옴. Claude가 프로젝트 문서 검색 결과 "Jev"가 외부에 정의된 바 없다고 잘못 답변함.

**재질문 후 사용자 지시:** "Jev에 대해서 한번 리서치해보고 다시 답해줘"

**WebSearch 결과:** Jev는 TypeSafe AI가 2026-09-15 공개한 실제 결정 모델(System 1) — 상태+타입 후보를 주면 확률·확신도 포함 타입 결정을 70~500ms에 반환. BUG-01 문서의 "후보 중 선택" 설계와 정확히 일치. Vercel AI Gateway 최속 채택 사례로 보도됨.

**2차 질문(정정 반영):** 실제 Jev를 쓸지, Gemini로 같은 역할을 흉내낼지, A/B 실험할지

| Option | Description | Selected |
|--------|-------------|----------|
| 실제 Jev 사용 (신규 벤더 온보딩) | 문서가 의도한 대로 실제 결정 모델을 쓴다. 데이터 처리 정책 검토 필요 | ✓ |
| Gemini Flash-Lite로 역할 대체 | 신규 벤더 온보딩 없이 기존 어댑터로 흉내 | |
| 카테고리당 실험해서 결정(A/B) | 추상화 계층만 만들고 페이즈 내 평가로 최종 선택 | |

**User's choice:** 실제 Jev 사용 (신규 벤더 온보딩)
**Notes:** Jev는 출시 1주일 이내 신생 벤더이므로 API 안정성·데이터 정책이 아직 검증되지 않음. research-phase에서 공식 문서 확인 필요.
