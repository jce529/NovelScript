    ```ts
    export type DecisionProvider = 'jev';

    /** 어떤 결정 단계인지 — 로그·지표·평가에서 단계별 호출 수/지연을 구분하는 데 쓴다 (15-REVIEWS 15-01/15-08). */
    export type DecisionType = 'task' | 'category' | 'folder' | 'template';

    export interface DecisionCandidate {
      /** 불투명 키 — 실제 DB id를 절대 담지 않는다 (BUG-01 §Jev 입력 계약). */
      key: string;
      [field: string]: unknown;
    }

    export interface DecisionRequest {
      decisionType: DecisionType;
      /** 호출 추적용 UUID (crypto.randomUUID()). 로그에 남는 유일한 요청 식별자. */
      requestId: string;
      /** 요청/챕터 문맥/멘션 사실 등 판단 문맥. */
      state: Record<string, unknown>;
      candidates: DecisionCandidate[];
    }

    export interface DecisionResult {
      /** 항상 request.candidates 중 하나의 key — 어댑터가 membership을 보장한다. */
      key: string;
      confidence: number; // 0..1 유한수
      probabilities: Record<string, number>; // 각 값 0..1 유한수
      latencyMs: number;
      modelVersion: string;
    }

    export interface DecisionClient {
      readonly provider: DecisionProvider;
      /** Throws ONLY DecisionCallError (sanitized). Never throws a raw fetch/JSON/Zod error. */
      decide(request: DecisionRequest): Promise<DecisionResult>;
    }

    export type DecisionErrorKind = 'rate_limited' | 'unavailable' | 'config' | 'invalid_response';

    export interface SanitizedDecisionError {
      provider: DecisionProvider;
      status: number | null;
      kind: DecisionErrorKind;
      /** allowlist: 'API_KEY_MISSING' | 'MODEL_VERSION_MISSING' | 'TIMEOUT' | 'HTTP_<status>' | 'BAD_JSON' | 'SCHEMA_MISMATCH' | 'UNKNOWN_KEY' | null */
      providerErrorCode: string | null;
    }
    ```

    ```ts
    import { JEV_DEFAULT_TIMEOUT_MS } from './config';

    const unit = z.number().finite().min(0).max(1);
    const JevResponseSchema = z.object({
      key: z.string().min(1),
      confidence: unit,
      probabilities: z.record(z.string(), unit).optional(),
    });

    export function createJevClient(env: Record<string, string | undefined> = process.env): DecisionClient {
      const apiKey = env.TYPESAFE_API_KEY;
      const model = env.JEV_MODEL_VERSION;
      if (!apiKey) throw new DecisionCallError({ provider: 'jev', status: null, kind: 'config', providerErrorCode: 'API_KEY_MISSING' });
      if (!model) throw new DecisionCallError({ provider: 'jev', status: null, kind: 'config', providerErrorCode: 'MODEL_VERSION_MISSING' });
      const url = env.TYPESAFE_API_BASE_URL || 'https://api.typesafe.ai/v1/systemone';
      const timeoutMs = Number(env.JEV_TIMEOUT_MS) > 0 ? Number(env.JEV_TIMEOUT_MS) : JEV_DEFAULT_TIMEOUT_MS;

      return {
        provider: 'jev',
        async decide(request: DecisionRequest): Promise<DecisionResult> {
          const started = Date.now();
          // 단일 sanitized 경계: fetch / HTTP 상태 / JSON 파싱 / 스키마 / membership 전부 이 try 안 (15-REVIEWS 15-01 HIGH)
          try {
            const res = await fetch(url, {
              method: 'POST',
              headers: { Authorization: `Bearer ${apiKey}`, 'Content-Type': 'application/json' },
              body: JSON.stringify({ model, state: request.state, candidates: request.candidates }),
              signal: AbortSignal.timeout(timeoutMs),
            });
            if (!res.ok) throw new DecisionCallError(toSanitizedDecisionError({ status: res.status }));
            let raw: unknown;
            try { raw = await res.json(); } catch {
              throw new DecisionCallError({ provider: 'jev', status: res.status, kind: 'invalid_response', providerErrorCode: 'BAD_JSON' });
            }
            const parsed = JevResponseSchema.safeParse(raw);
            if (!parsed.success) {
              throw new DecisionCallError({ provider: 'jev', status: res.status, kind: 'invalid_response', providerErrorCode: 'SCHEMA_MISMATCH' });
            }
            const allowed = new Set(request.candidates.map((c) => c.key));
            if (!allowed.has(parsed.data.key)) {
              throw new DecisionCallError({ provider: 'jev', status: res.status, kind: 'invalid_response', providerErrorCode: 'UNKNOWN_KEY' });
            }
            // probabilities 중 후보 밖 키는 버린다 (후보 밖 키가 지표/로그로 흘러가지 않게)
            const probabilities = Object.fromEntries(
              Object.entries(parsed.data.probabilities ?? {}).filter(([k]) => allowed.has(k))
            );
            return { key: parsed.data.key, confidence: parsed.data.confidence, probabilities, latencyMs: Date.now() - started, modelVersion: model };
          } catch (err) {
            if (err instanceof DecisionCallError) throw err;
            throw new DecisionCallError(toSanitizedDecisionError(err));
          }
        },
      };
    }
    ```
