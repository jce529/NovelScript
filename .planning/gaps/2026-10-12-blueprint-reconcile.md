# 청사진 기준 phase 정합성 재판정 (2026-10-12)

**기준**: 청사진(`design/UI-DESIGN-BACKLOG.md` 확정 결정, 보드 1~43, `design/WORLD-TREE.md`)이 해당 phase 영역에 필수로 요구하는 기능이 코드에 없으면, phase가 "완료"였더라도 완료 표시를 취소하고 **재개(Reopened)** 로 표시한다. 재개는 "코드를 버린다"가 아니라 "청사진 갭이 남았으니 논의·research·plan을 이어간다"는 표식이다. 기존 구현과 검증 기록은 그대로 유효하다.

**근거**: Haiku 서브에이전트 4개(phase 묶음별)가 코드·문서를 정적으로 조사했고(테스트·브라우저·원격 DB는 미확인), 핵심 주장은 직접 재확인했다. 이 문서는 스냅샷이다. 상세 영역별 목록은 `2026-10-12-blueprint-gap.md`, 상태 용어는 ROADMAP Progress 절.

**판정 기준(일관 적용)**
- 재개: 청사진이 그 phase의 목표 영역으로 확정한 기능이 빠져 있거나 확정 결정과 반대로 구현됨.
- 유지: 갭이 있어도 다른 phase 소관이거나 phase 목표 밖(신규 영역). 갭은 "미배정 청사진 영역"으로 모은다.
- 미착수 phase는 선행 결정만 표기.

## phase별 목표와 구현 기능 (청사진 기준)

### Phase 2 — 스튜디오 코어 (재개)
- 목표: AI 없이 설정집과 회차를 만들고 발행한다.
- 구현: KB 문서 CRUD·5종 템플릿, 작품별 트리, 회차 저장·순서·발행·취소, 가격 10·30·50·100.
- 청사진 갭: 기본 템플릿 5종 읽기 전용+사본 규칙, 우클릭 이름 바꾸기(모바일 길게 누르기), 템플릿 섹션과 `새 문서 (템플릿에서)`, 좌·우 패널 접기, 저장 상태 칩, 설정 문서 `세계관 공개` 토글(보드 25는 별도 영역).
- 이어갈 일: **discuss** — 코드 주석이 "템플릿 편집 허용(D-10)"을 의도적 결정으로 적고 있어 확정 결정과 충돌한다. 어느 쪽을 따를지 먼저 정한다.

### Phase 3 — 독자 코어 (재개)

- 청사진 갭: 독자 헤더 2단(잔액+충전·검색·메인 탭·서브 행), 홈(가로 슬라이더·루키·명예의 전당), 작품 상세 4탭(소개·회차·세계관·리뷰)·연독률/완독률 메타·신고 상단 고정·10화 단위 회차 목록, 뷰어 설정 5항목·설정 저장·탭 시 상하단 바·경계 처리, 스크롤 위치 진도·완독 판정, 랭킹 완독률·연독률 기준, 랭킹 목록 창·내서재·연재 목록·검색·작가 페이지·명예의 전당(라우트 없음).
