# UI 설계 이어가기 (컨텍스트를 정리해도 여기서부터)

마지막 갱신: 2026-10-10. 새 세션이나 다른 기기에서 "UI 설계 이어서 해줘"라고 하면 이 문서부터 읽는다. 항목을 끝낼 때마다 아래 체크박스와 "현재 위치"를 고친다.

## 재개 절차

1. 이 문서 → `.planning/design/UI-DESIGN-BACKLOG.md`(확정된 UI 결정·영역별 백로그) 순서로 읽는다.
2. 아래 "진행 순서"에서 첫 번째 미완료 항목이 다음 작업이다. 사용자가 다른 화면을 지정하면 그것을 먼저 한다.
3. 목업 작업 방법:
   - 캔버스 원본: Artifact https://claude.ai/artifact/UobbbTgkjDTbdDyrQXvyys (비공개, 소유자만 열람). 갱신하려면 Artifact 도구로 같은 `url`에 발행한다.
   - 저장소 사본: `.planning/design/mockups/project/` (`canvas.json` + 보드별 `*.dc.html`). Artifact를 읽을 수 없으면 이 사본으로 새 캔버스를 만들 수 있다(Design 타입, 파일은 `project/` 아래에 같은 이름으로).
   - 새 보드는 `canvas.json`의 `boards`와 `order`에 추가한 뒤 `.dc.html`을 쓰고, 발행 후 저장소 사본도 같이 갱신한다. 좌표는 기존 줄 배치(행 간격 120px 이상)를 따른다.
   - 톤: 현재 앱 스타일(흰 카드, 중립 회색, 인디고 포인트 하나). 샘플 데이터는 가짜임을 답변에 밝힌다.
4. 작업 후: 목업을 Artifact에 발행 → 저장소 사본 갱신 → 확정된 내용을 `UI-DESIGN-BACKLOG.md`의 "확정된 UI 결정"에 추가 → 이 문서 체크박스 갱신 → 커밋·푸시. PR은 요청할 때만.
5. 화면이 확정되면 해당 phase의 `*-UI-SPEC.md`로 문서화하는 것은 별도 단계다(CLAUDE.md "UI phase 완료 후 예시 목업 제공" 규칙 참고).

## 현재 위치

- 완료(검토 대기): 화면 맵, 독자 헤더, 독자 홈, 랭킹 목록 창, 작품 상세(모바일·데스크톱), 스튜디오 3패널 셸(개요), 통합 설정 허브(AI 섹션).
- 다음: 진행 순서 1번 독자 뷰어.
- 사용자 답변 대기(미결정, `UI-DESIGN-BACKLOG.md` 하단): 회차 페이지 버튼 묶음 방식, 작품 상세 모바일의 잔액·검색 생략, 메인 탭·서브 행 항목 이름, 명예의 전당 도착지, 세계관 진도 기준.

## 진행 순서

각 항목의 산출물은 "Artifact 보드 추가 + 저장소 사본 갱신 + 백로그 문서 갱신"이다. 보드 번호는 `canvas.json`의 다음 번호를 쓴다.

- [x] 0. 화면 맵·헤더·독자 홈·랭킹 목록 창·작품 상세·스튜디오 셸·설정 허브 (보드 1~10)
- [ ] 1. **독자 뷰어** (모바일·데스크톱) — 하단 시트(다음 화 결제·리뷰 작성), 다크 모드·글꼴 조절, 유료 회차 소장 유도, 스크롤 진도 연동
- [ ] 2. **토큰 충전 모달·회차 소장 확인** — 헤더 `+`와 뷰어 결제가 만나는 흐름, 잔액 부족 상태 (Toss 연동 전, 화면만)
- [ ] 3. **스튜디오 에디터 상세** — 좌 트리·중 캔버스·우 AI 코워커, 회차·설정 문서 통합, 모바일
- [ ] 4. **세계관 공개 설정(작가)** — 설정 문서별 공개 여부·등장 회차 입력, AI 시각화 에셋 관리
- [ ] 5. **작가 대시보드** — 작품 그리드, 회차별 완독률·이탈 구간, 경제 관리(토큰·BYOK)
- [ ] 6. **내서재** — 이어 읽기 · 선호작 · 알림 구독 · 소장함
- [ ] 7. **무료·유료 연재 목록** — 랭킹 목록 창 구조 재사용
- [ ] 8. **명예의 전당 목록 · 리뷰 작성 · 검색 결과**
- [ ] 9. **빈 상태·비로그인 상태** (전 화면 일괄)
- [ ] 10. **작가 정산·수익 확인, 통합 설정 허브 나머지 섹션(계정·지갑·작품)**
