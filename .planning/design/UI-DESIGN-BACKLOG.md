작성: 2026-10-10. 최종 청사진(`docs/5-1`~`5-4`)과 2026-10-10 결정(`.planning/PROJECT.md` Key Decisions)을 기준으로, 아직 화면 설계가 필요한 곳을 영역별로 모은 문서다. 설계가 끝난 항목은 상태 열을 갱신하고, UI-SPEC으로 확정되면 해당 phase의 `*-UI-SPEC.md` 경로를 적는다.

- 요구사항 ID·phase는 아직 배정하지 않았다. 신규 항목은 설계 확정 후 REQUIREMENTS에 먼저 정의한다(SSOT `확정된 최종 청사진 결정` 절 참고).
- 목업 캔버스(비공개 Artifact): https://claude.ai/artifact/UobbbTgkjDTbdDyrQXvyys — 1~10번 보드. 목업은 이 저장소에 파일로 저장돼 있지 않으므로, 확정된 내용은 아래 "확정된 UI 결정"에 글로 남긴다.
- 디자인 톤: 현재 앱 스타일(shadcn + 인디고 포인트 하나, 흰 카드·중립 회색) 유지·확장.

## 상태 범례

- **설계됨**: 목업이 있고 사용자 검토 중이거나 확정. 아직 UI-SPEC 아님
- **개요만**: 화면 맵에만 있고 상세 시안 없음
- **없음**: 시안 없음
- **구현됨**: 현재 코드에 화면이 있음(청사진과 다를 수 있음)

| 랭킹 목록 창 | 서브 행 + `태그검색`·장르 칩 + 정렬·기간·연재 선택 + 순위 그리드(순위 숫자·연독률 배지). 모바일 3열 | 7·8번 |
| 루키 쿼터존 | 최소 10화(또는 5만 자) 이상 연재한 신작만 노출 | 5·6번 |
| 명예의 전당 | 리뷰 하이라이트 버튼은 `1화부터 정주행하기` 또는 `해당 에피소드 시작부터 읽기`만(중간 회차로 바로 보내지 않음) | 5·6번 |
| 작품 상세 | 탭 4개(소개 · 회차 · 세계관 · 리뷰). 메타 헤더에 연독률·완독률·조회·좋아요, 상단에 `불일치·표절 신고` 고정. 선호작·알림은 상세 상단 바. 모바일은 상세 전용 상단 바(전역 헤더 숨김), 데스크톱은 전역 헤더 유지. 현재의 `작품설정` 탭은 `세계관`으로 대체 | 9·10번 |
| 세계관 탭 | 현재 열람 진도 이후에 처음 등장하는 항목은 목록에서 제외(스포일러 방지), 종류 필터 칩도 보이는 종류만. 등장한 항목의 세부 내용 일부는 `O화 열람 시 해제`로 가림. AI 생성 이미지 표기 | 9·10번 |
| 회차 목록 | 10화 단위 페이지. 페이지 버튼 5개씩 묶음(양옆 화살표로 이전·다음 5페이지), 오른쪽 끝에 페이지 입력창과 `이동`. 묶음 방식(고정 vs 이동식)은 확인 대기 | 9·10번 |
| 스튜디오 에디터 | 회차와 설정 문서를 하나의 3패널 셸로 통합(좌 트리 / 중 캔버스 / 우 AI 코워커). 우측에는 모델 피커만 두고 키 관리·MCP는 설정으로 연결 | 3번 |
| AI 설정 | 키 관리 · 기본 모델 · MCP 연결 · 이번 달 사용량을 스튜디오 통합 설정 허브('AI' 섹션)에 모음 | 4번 |

## 권장 진행 순서

1. 독자 뷰어 → 토큰 충전·소장 확인 (독자 핵심 루프의 끝과 결제 접점)
2. 에디터 상세 + 세계관 공개 설정 (독자 세계관 탭과 짝)
3. 내서재 → 무료·유료 연재 목록 → 명예의 전당·리뷰·검색
4. 빈 상태·비로그인 상태 (모든 화면에 걸쳐 마지막에 일괄)
5. 스토어 영역은 결제 phase 진행 상황과 에셋 스토어 범위 결정 이후

## 미결정·확인 대기

- 회차 페이지 버튼 묶음: 고정 묶음(1–5, 6–10 …) vs 선택 페이지가 가운데로 오는 이동식 창
- 작품 상세 모바일에서 잔액 칩·검색이 빠지는 것이 맞는지
- 메인 탭·서브 행의 항목 이름과 구성(임의안)
- 명예의 전당 더보기의 도착지를 랭킹 창의 서브 탭으로 둘지 별도 화면으로 둘지
- 세계관 탭 "진도" 기준(읽은 최대 회차 / 마지막 읽은 회차)
