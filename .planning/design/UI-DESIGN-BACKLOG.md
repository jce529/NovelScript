# UI 설계 백로그 (독자 · 작가 · 스토어)

작성: 2026-10-10. 최종 청사진(`docs/5-1`~`5-4`)과 2026-10-10 결정(`.planning/PROJECT.md` Key Decisions)을 기준으로, 아직 화면 설계가 필요한 곳을 영역별로 모은 문서다. 설계가 끝난 항목은 상태 열을 갱신하고, UI-SPEC으로 확정되면 해당 phase의 `*-UI-SPEC.md` 경로를 적는다.

- 목업 캔버스(비공개 Artifact): https://claude.ai/artifact/UobbbTgkjDTbdDyrQXvyys — 1~21번 보드. 소스 사본은 `.planning/design/mockups/project/`에 있다. 이어서 작업하는 절차와 진행 순서는 `UI-DESIGN-RESUME.md`.
- 디자인 톤: 현재 앱 스타일(shadcn + 인디고 포인트 하나, 흰 카드·중립 회색) 유지·확장.

## 상태 범례

- **설계됨**: 목업이 있고 사용자 검토 중이거나 확정. 아직 UI-SPEC 아님
- **개요만**: 화면 맵에만 있고 상세 시안 없음
- **없음**: 시안 없음
- **구현됨**: 현재 코드에 화면이 있음(청사진과 다를 수 있음)

| 독자 뷰어 | 기본은 본문만 보이는 깔끔한 화면. 본문을 탭·클릭하면 상단·하단 바가 나타남. 상단: 왼쪽 홈(작품 상세로 바로 이동)·목록(회차 목록이 뷰어 위에 표시), 오른쪽 설정(말풍선으로 뷰어를 살짝 가리며 표시). 설정 항목: 글꼴 · 뷰어 모드(라이트/다크/시스템) · 글자 크기 · 여백 크기(본문 좌우 여백) · 줄 간격. 상단에 `정주행` 토글 추가. 하단: 이전 화 · 댓글 · 다음 화. 유료 회차: 이전 화(무료·소장·대여 완료)에서 다음 화를 누르거나 본문 끝에서 아래로 밀면 `소장`/`대여` 선택 팝업. 정주행 ON이면 보유 토큰이 소진될 때까지 다음 화로 이동할 때마다 자동 결제하고, 소진되면 정주행이 꺼지며 팝업. 자동 결제 방식(소장/대여)은 독자 계정 설정에서 바꾸며 기본값은 대여. 댓글: 해당 회차 댓글 창에서 다른 독자·작가 댓글 열람과 작성, 익명 불가(독자 닉네임 공개) | 11·12번 |
| 댓글 신고·답글 | 댓글과 답글 모두에 `답글`·`신고`(본인 글 제외). 작성자가 독자든 작가든 신고 가능. 신고 사유: 욕설·비하·혐오 / 스포일러 / 광고·도배 / 기타. 신고가 접수되면 관리자가 검토해 댓글 숨김 · 경고 · 댓글 정지(1일·7일·30일·영구) · 계정 정지(7일·30일·영구) · 기각을 선택. 작가 계정도 같은 기준 | 11·12·13번 |
| 독자 계정 설정 | 닉네임 변경 버튼(변경하면 14일 동안 재변경 불가, 변경 후 남은 일수 표시, 이전 댓글에도 새 닉네임 반영). 자동 결제 방식(대여 기본 / 소장)은 카드 두 장 중 하나를 눌러 즉시 전환, 언제든 자유롭게 변경 | 14·15번 |
| 뷰어 경계 | 첫 화에서는 이전 화, 마지막 화에서는 다음 화 버튼을 회색·블러로 흐리게 해 암시. 마지막 화에서 스크롤을 끝까지 내리거나 다음 화를 누르면 "마지막 화예요"(새 회차 알림 켜기) 알림창을 띄우고 멈춤 | 11·12번 |
| 숨긴 회차 | 이미 공개됐다가 관리자가 숨긴 회차와, 숨긴 회차를 링크로 직접 연 경우 모두 같은 `볼 수 없는 회차` 화면을 쓴다. 이어 읽기 목록도 일괄적으로 `볼 수 없음`으로 표시. 선호작 알림에는 숨김 사실을 알리지 않고, 숨겼다가 다시 공개하면 `공개` 알림만 보낸다 | 규칙(화면 미설계) |
| 빈 상태 | 자동으로 다른 화면으로 돌려보내지 않고, 화면 안에 짧은 안내와 다음 행동 버튼을 보여준다. 12종 시안(내서재 4종·비로그인·댓글 0개·리뷰 0개·검색 결과 없음·목록 비었음·루키 구역 비었음·불러오기 실패·볼 수 없는 회차). 문구는 임시안이며 타 서비스 조사는 근거를 얻지 못해 일반 관행으로 진행, 사용자 캡처로 추후 보완 | 16번 |
| 대여 상태 표시 | 대여 알림은 따로 보내지 않는다. 회차 상태는 `대여중`(상태 아래에 작은 글씨로 `대여 만료 일시 까지`)과 `대여 만료`(빨간색) 두 가지만 표시. 만료된 회차를 누르면 소장/대여 결제 팝업이 뜬다 | 9·10번 |
| 루키 쿼터존 비었을 때 | 구역을 숨기지 않고 안내 카드를 보여준다 | 16번 |
| 댓글 권한 규칙 | 수정은 작성자 본인만. 삭제는 작성자 본인 또는 관리자. 좋아요·신고는 누구나(본인 글 신고 제외). 작가도 같은 규칙 | 규칙(화면 미설계) |
| 읽기 진도 규칙 | 진도는 스크롤 위치(끝 기준)에 맞춰 저장하고, 다시 들어오면 저장된 위치로 복귀. 완독은 끝까지 스크롤하고 사람이 읽는 속도 기준 최소 읽기 시간을 넘겼을 때만 인정(너무 빠른 스크롤은 미인정). 속도 기준 값은 미정 | 규칙(UI-SPEC에서 확정) |
| 회차 목록 → 뷰어/결제 | 작품 상세 회차 목록에서 무료·읽음·소장중·대여중 회차를 누르면 바로 해당 회차 뷰어로 이동. 소장·대여하지 않은 유료 회차를 누르면 뷰어와 같은 소장/대여 팝업. 결제 시 토큰이 부족하면 토큰 충전 창(100토큰 1,000원 / 550토큰 5,000원)을 띄우고, 충전 후 결제로 복귀. 상태 표시: 소장중 / 대여중 | 9·10번 |
| 토큰 충전소 | 묶음·결제 수단은 화면 고정값이 아니라 운영에서 관리하는 목록(이벤트 묶음·기간 한정 라벨·새 결제 수단을 코드 수정 없이 추가·교체). 목업의 3번째 묶음(이벤트)과 4번째 결제 수단이 예시. 헤더 `+`, 뷰어·작품 상세의 잔액 부족, 정주행 소진이 같은 모달을 연다. 묶음 2종(100토큰 1,000원 / 550토큰 5,000원) 선택 + 결제 수단(카드·카카오페이·토스페이, 임시) + 요약 후 결제. 잔액 부족으로 열렸으면 완료 화면에 `결제하던 회차로 돌아가기`. 실패 시 청구 안 됨 안내 + `다시 시도`. Toss 연동 전이라 화면만 | 17번 |
| 내서재 | 서브 행 4종이 곧 탭. 이어 읽기: 진도 바 + `이어 읽기` + 오른쪽 X 버튼으로 기록 삭제(숨긴 회차는 `볼 수 없음`). 선호작: 정렬 3종 + `새 회차` 배지. 알림 구독: 작품별 스위치. 소장함: 필터(전체·소장중·대여중·대여 만료) + 상태 표시, 만료 회차를 누르면 소장/대여 팝업 | 18번 |
| 무료·유료 연재 목록 | 랭킹 목록 창과 같은 구조. 신작은 연재 시작일 기준, 인기는 완독률·조회수 기반. 메인 탭이 무료/유료를 전환하고 서브 행(전체·신작·인기·완결)이 필터. 카드에 NEW·완결 라벨과 가격 문구. 조건에 맞는 작품이 없으면 `필터 초기화` 안내 | 19번 |
| 명예의 전당·리뷰 작성 | 리뷰 카드 목록(작품 표지·별점·읽은 회차·스포일러 표시·도움이 됐어요·신고). 읽기 버튼은 `1화부터 정주행하기` / `N화 시작부터 읽기`만. 우수 리뷰 기준 안내 박스(3화 이상 읽은 뒤 작성·50자 이상·도움 수 기준, 임시 값으로 진행하고 나중에 값만 교체). 작성 폼: 별점·본문(50자 이상)·스포일러 표시, 닉네임 공개 | 20번 |
| 검색 결과 | 헤더 검색창에서 도착. 자동완성은 넣지 않고, 검색창을 누르면 `최근 검색어`(개별·전체 삭제)와 `추천 검색어`를 분리해 보여준다. 전체·작품·태그·작가 탭. 작품 결과를 누르면 바로 작품 상세, 작가 결과는 키워드가 이름에 들어간 작가 명단이고 누르면 작가 페이지. 결과 없음은 16번 빈 상태와 같은 구성 | 21번 |
| 작가 페이지 | 작가 프로필(소개·작품 수·연재중/완결 수) + 작품 그리드(연재 상태 필터, 업데이트·신작·인기 정렬). 작품 상세의 작가 이름과 검색 결과의 작가 항목에서 진입. 공개 작품만 노출 | 22번 |
| 스튜디오 에디터 | 회차와 설정 문서를 하나의 3패널 셸로 통합(좌 트리 / 중 캔버스 / 우 AI 코워커). 우측에는 모델 피커만 두고 키 관리·MCP는 설정으로 연결 | 3번 |
| AI 설정 | 키 관리 · 기본 모델 · MCP 연결 · 이번 달 사용량을 스튜디오 통합 설정 허브('AI' 섹션)에 모음 | 4번 |

## 미결정·확인 대기

- 회차 페이지 버튼 묶음: 고정 묶음(1–5, 6–10 …) vs 선택 페이지가 가운데로 오는 이동식 창
- 작품 상세 모바일에서 잔액 칩·검색이 빠지는 것이 맞는지
- 메인 탭·서브 행의 항목 이름과 구성(임의안)
- 명예의 전당 더보기의 도착지를 랭킹 창의 서브 탭으로 둘지 별도 화면으로 둘지
- 세계관 탭 "진도" 기준(읽은 최대 회차 / 마지막 읽은 회차)
- 추천 검색어를 운영 선정과 인기 검색어 중 어떤 비율로 채울지, 작가 페이지에 둘 추가 정보(팔로우 등)는 아직 정하지 않았다.
