# NovelScript 홍보 콘텐츠 기획 (논의 정리)

작성: 2026-11-03. 사용자와의 기획 논의 결과를 정리한 문서다. 확정된 결정과 아직 정해지지 않은 항목을 구분해 적는다. 기능 상태는 `.planning/ROADMAP.md` Progress 표(2026-11-02 기준)를 따른다.

## 1. 기본 전제 (확정)

| 항목 | 내용 |
|---|---|
| 타깃 | 웹소설 작가 지망·현직. 독자는 본편을 통해 같이 유입 |
| 노출 방식 | 목소리(내레이션)만. 화면 녹화와 자막 중심 |
| 목표 | 팔로워 사전 축적과 베타 모집 병행 |
| 제작 시간 | 주 5~8시간 (본편 집필 포함) |
| 채널 | 유튜브 쇼츠·영상, 인스타 릴스·카드뉴스 |

## 2. 핵심 콘셉트 (확정)

- **쇼츠는 제작기다.** 어떤 문서를 만들고, 그 문서를 AI와 어떻게 써서 실제 소설 장면을 만드는지 보여 준다. 장면이 나오는 데까지만 보여 준다.
- **본편은 웹에서 무료 공개한다.** 회차마다 제작기가 유튜브·인스타에 있음을 안내하고, 쇼츠 말미에서는 본편 링크로 보낸다.
- **목표 구조:** 시청자층과 독자층을 서로 공유하고, 장편 하나를 시리즈로 연재한다.
- **세계관 공개:** 공용으로 쓸 수 있는 세계관을 풀어 시청자가 설정을 알 수 있게 한다.

## 3. B안: 하나의 세계관, 여러 시점의 동시 연재 (확정)

- 세계관 문서를 한 번 만들고, 여러 시점의 연재가 같은 설정집을 `@`멘션해서 쓴다.
- 같은 설정집을 쓰는데도 설정이 안 무너지는 장면이 "설정 붕괴 방지"의 데모다.
- 세계수의 동시 진행 규칙(`.planning/design/WORLD-TREE.md` 규칙 11)과 맞는다. 세계수는 코드 완료·검증 대기 상태라 "개발 중 베타 화면"으로 표기한다.
- 주인공 후보를 만들어 투표로 본편 시점을 정하는 방식도 쓸 수 있다.

**B안이 돌아가려면 정해야 할 조건**

- 동시에 돌릴 시점 개수와 시점별 연재 주기
- 시점 수만큼 늘어나는 사전 확보 분량
- 시점 간 사건 순서와 정보 공개 시점 점검 방법
- 주 5~8시간에 전부 들어가는지 확인. 안 들어가면 시점 수를 줄이거나 주기를 늘린다

## 4. 쇼츠 포맷 (30~45초)

| 구간 | 내용 |
|---|---|
| 0~3초 | 결과물 장면 한 줄을 훅으로 |
| 3~8초 | 이번 편이 푸는 질문 |
| 8~28초 | 과정 하나만 (문서 만들기, 멘션, AI 초안, 직접 수정 중 하나) |
| 28~35초 | 결과, 수정 전후 |
| 35~45초 | 본편 링크 안내 + 다음 편 예고 |

B안 특화 소재: 같은 사건을 두 시점으로 쓰는 편, 서로 다른 시점이 같은 문서를 멘션하는 편, 세계수에서 작품이 나란히 걸리는 편.

## 5. 파일럿 구성

- 준비(게시 없음): 세계관·인물 문서와 사전 집필
- 카드뉴스 1: 작품 소개 (세계관 개요, 라이선스 한 줄, 본편 링크)
- 쇼츠 1~5: 세계관 뼈대 → 인물 문서 → 멘션 → 1화 집필 → 설정 충돌 잡기. 이후 "N화 제작기" 반복
- 카드뉴스 2: 설정 문서 체계 도식

## 6. 화면에 보여도 되는 기능 (로드맵 기준)

| 구분 | 기능 | 근거 |
|---|---|---|
| 가능 | 설정집 트리, `@`멘션 에디터, 프리셋·문체, 호출 전 비용 추정 | Phase 2 완료, Phase 4 코드 완료(실키 UAT 대기) |
| 조건부 | 세계수 | Phase 18 코드 완료, 실DB·브라우저 검증 대기, 공유 DB 미적용. 개발 중 표기 |
| 확인 후 사용 | 문서 생성, 설정 문서 AI 대화 | Phase 15 활성화 차단, Phase 16 실검증 대기. 촬영 전 직접 돌려 되는 흐름만 |
| 보류 | MCP 연결, BYOK 실사용, 결제 | Phase 12 인수 대기·Phase 13 미실행, BYOK UAT 대기, Toss 키 대기 |

## 7. 촬영 전 체크리스트

1. 보여 줄 기능이 실제로 동작하는지 직접 확인
2. 본편을 올릴 독자 화면이 외부에서 접속되는지 확인
3. 세계관 2차 창작 허용 범위를 한 줄 라이선스로 정하고 변호사 자문 항목에 포함 (`.planning/business/변호사_자문_필요사항.md` 참고)
4. AI 생성물 표기 방식과 플랫폼별 AI 콘텐츠 표기 정책 확인 (웹 조사 필요)
5. "품질 보장" 같은 단정적 광고 문구는 피하고 과정을 정직하게 표시 (소요 시간·수정 횟수 표시)
6. 본편 링크에 UTM을 붙여 쇼츠 유입 측정
7. 사전 확보 분량을 먼저 쓰고 공개 시작 (준비 주간)

## 8. 아직 정해지지 않은 것

- 세계관의 장르와 한 줄 규칙 (후보 방향: 규칙형 판타지, 현대 이능물, 직업 세계관)
- 시점 개수, 연재 주기, 사전 확보 분량
- 본편 공개일과 제작기 공개일의 관계 (스포일러 방지)
- 투표 여부, 방식, 대상
- 채널명·브랜딩, 카드뉴스 CTA가 가리킬 곳

## 9. 검토했다가 접은 안

- **세계관 3개 중 투표(A안):** 개념 단계만 3배 부담이고 세계관이 갈라진다. 투표 대상을 "세계관"이 아니라 "주인공 시점"으로 바꾸는 방식만 남겼다.
- **세계관 1개 + 본편 1개 + 짧은 사이드(C안):** 부담이 가장 작은 대안이었다. 사용자가 B안을 선택해 보류. B안 조건이 시간 안에 안 들어갈 때의 후퇴 지점으로 남겨 둔다.
