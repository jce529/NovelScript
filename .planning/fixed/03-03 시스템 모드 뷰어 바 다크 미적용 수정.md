# 03-03: 시스템 모드 뷰어 바 다크 미적용 수정

## 증상
설정의 뷰어 모드를 '시스템'으로 두고 OS가 다크일 때 본문은 어두운데 상단 헤더·하단 바·보기 설정 팝오버가 흰색이었다. 라이트·다크 고정 모드는 정상이었다.

## 원인
03-16이 뷰어 루트에 `preferences.mode === 'dark'`일 때만 `dark` 클래스를 붙였다. 바는 `bg-background`처럼 `.dark` 토큰에 의존하는데, 시스템 모드의 본문 색만 `viewer.module.css`의 `prefers-color-scheme` 미디어 쿼리로 처리돼서 바는 라이트 토큰 그대로였다. 설정 팝오버는 Portal로 `body`에 그려져 루트의 클래스가 닿지 않는 별도 문제도 있었다(고정 다크에서도 팝오버는 라이트 토큰이었을 수 있다).

## 수정
- `useViewerDark(mode)`(`components/reader/viewer-dark.ts`): `matchMedia('(prefers-color-scheme: dark)')`를 `useSyncExternalStore`로 구독해 시스템 모드에서 OS 다크를 `dark` 클래스로 반영한다. 서버 스냅샷은 `false`라 hydration 불일치가 없다. Tailwind `dark:` 변형이 클래스 기반이라 CSS 미디어 쿼리만으로는 `dark:` 유틸이 따라오지 못해 JS 방식을 골랐고, 토큰 중복도 피한다.
- 뷰어 루트 클래스와 설정 팝오버(`PopoverContent`)에 같은 `dark` 값을 적용한다.

## 검증
- `tests/reader/viewer-dark.test.ts` 2건 추가, `viewer-wiring`·`viewer-settings` 포함 21건 통과, `tsc` 통과(2026-11-11).
- 브라우저(일회용 DB 개발 서버, 비로그인): OS 다크 에뮬레이션 + 시스템 모드에서 루트 `dark`, 헤더·하단 바·팝오버 모두 어두움. 라이트 에뮬레이션으로 바꾸면 새로고침 없이 전부 밝아짐.
- 미확인: 고정 라이트·다크 모드의 브라우저 재확인(판정 규칙은 단위 테스트로 확인).
- 남은 후속: 목차 시트, 끝 다이얼로그, 신고 다이얼로그도 Portal이라 같은 방식으로 다크가 안 닿을 수 있다. 이번 범위 밖.
