# 03-02: 토글 경합 수정

## 증상
같은 대상에 동시 토글 요청이 겹치면 둘 다 같은 상태를 읽고 한 번만 반영될 수 있었다.

## 원인
상태 조회와 쓰기가 별도 쿼리라 원자적이지 않았다.

## 수정
- `0019_reader_atomic_toggle.sql`: `toggle_work_likes/bookmarks/subscriptions(p_work_id)` RPC. `auth.uid()`·`user_can_write` 검사, (테이블, 작품, 사용자) 단위 `pg_advisory_xact_lock`으로 직렬화.
- 버튼별 `useTransition` pending으로 비활성화·재클릭 무시.

## 검증
- 독립 연결 동시 2회(빈/기존 상태), on→off→on, 타 사용자 불변, 무인증·정지 거부를 3테이블×4로 통과(skip 0).
- 브라우저(로그인 세션): 좋아요 3회·선호작 3회 빠른 연속 클릭 → 최종 1회 반영, 새로고침 후에도 유지, 원복 확인.
