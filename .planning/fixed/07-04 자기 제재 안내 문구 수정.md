# 07-04: 자기 제재 안내 문구 수정

## 증상
관리자가 자기 작품 신고에 경고·정지를 걸면 서버는 막지만 화면에는 "입력 내용을 확인해 주세요."만 떴다.

## 원인
`self_sanction_forbidden`을 전용 코드 없이 `validation_failed`에 합쳐 매핑했다.

## 수정
- `AdminErrorCode`에 `self_sanction_forbidden`을 추가하고 RPC 오류 매핑을 전용 코드로 변경(DB 원문 미노출 유지).
- `moderation-form.tsx`의 `describeFailure`에 "자기 자신은 제재할 수 없어요." 분기를 추가.

## 검증
- 관련 테스트 95개 통과, tsc·eslint 통과.
- 브라우저(2026-10-02, 본인 계정에 임시 관리자 권한 부여): 본인 작품 신고에서 **경고**를 적용하자 `role="alert"`로 "자기 자신은 제재할 수 없어요."가 표시되고 제재는 기록되지 않았다.
- 미확인: 기간 정지(기간 미입력 상태)와 영구 정지의 실제 제출. 영구 정지는 확인 다이얼로그에서 취소했다(가드가 실패하면 본인 계정이 영구 정지되는 위험 때문). 경고와 같은 매핑·문구 경로를 쓴다.
