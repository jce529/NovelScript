# 02-04: 미분류 템플릿 안내 표시 정리

## 증상

루트 직속 커스텀 템플릿(카테고리 폴더 밖)은 사이드바 "내 템플릿 > 미분류" 그룹 제목으로만 보였다. 기대했던 행 단위 "미분류" 라벨과 툴팁("카테고리 미지정 · 카테고리 폴더로 이동해 주세요")은 어디서도 보이지 않았다.

## 원인

- 해당 라벨과 툴팁은 `TreeRow`의 `isUncategorizedTemplate` 블록에만 있었다.
- 02-10 사이드바 개편 뒤 템플릿은 `KbTemplateSection`/`TemplateEntryRow`가 그리므로 `TreeRow`는 템플릿을 그리지 않는다. 그 블록은 화면에서 도달할 수 없었다.
- `tests/kb/template-tree-ui.test.ts`는 `TreeRow`를 직접 렌더해서 통과하고 있었으므로 실제 화면과 어긋났는데도 잡히지 않았다.

## 수정

- `TreeRow`의 죽은 `isUncategorizedTemplate` 정의와 라벨·툴팁 JSX를 제거했다.
- 실제로 그려지는 `KbTemplateSection`의 "미분류" 그룹이 펼쳐져 있을 때 그룹 제목 아래에 "카테고리 폴더로 옮기면 분류돼요" 안내 문구를 보여 준다. 툴팁에 의존하지 않으므로 터치 기기에서도 보인다.
- 테스트는 죽은 블록 검사를 지우고, 실제 `KbTemplateSection`에 "미분류" 그룹과 안내 문구가 나오는지 검사하도록 바꿨다.
- 분류 기능은 새로 만들지 않았다. 사용자가 직접 폴더를 만들어 옮기는 기존 흐름을 그대로 둔다.
