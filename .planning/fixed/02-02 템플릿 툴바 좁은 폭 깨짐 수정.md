# 02-02: 템플릿 툴바 좁은 폭 깨짐 수정

## 증상

모바일 폭(약 375~450px)에서 내 템플릿을 열면 상단 툴바에서 템플릿 이름이 보이지 않고, "내 템플릿" 칩이 한 글자씩 세로로 쌓이며, 버튼 3개가 오른쪽에서 잘리거나 저장 상태 칩과 겹쳤다. 02-13 브라우저 게이트에서 사용자가 스크린샷으로 보고했다. 390px 실측: 이름 폭 0px, 칩 11×64px, 마지막 버튼이 툴바 오른쪽을 38px 초과.

## 원인

`template-editor-toolbar.tsx` 루트가 줄바꿈 없는 한 줄 flex였다. 이름 span에 최소 폭이 없어 0px까지 줄었고, 라벨 span에 `shrink-0`·`whitespace-nowrap`이 없어 글자 단위로 줄바꿈됐으며, 버튼 그룹은 줄어들지도 줄바꿈하지도 못했다. 저장 상태 칩은 툴바 바깥(페이지 래퍼) 오른쪽에 따로 붙어 폭을 더 빼앗았다.

## 수정

사용자가 확정한 방향대로 툴바를 위/아래 2단으로 나눴다.

- 위 단(`data-toolbar-tier="title"`): 이름(`min-w-0 truncate`) + 회색 `shrink-0 whitespace-nowrap` 라벨(`내 템플릿`/`기본 템플릿`). 기본 템플릿은 그 아래 읽기 전용 안내.
- 아래 단(`data-toolbar-tier="actions"`): `flex flex-wrap` 버튼 줄(이름 변경, 문서 저장, 이 템플릿으로 새 문서)과 끝의 저장 상태 칩(`statusSlot` prop 추가). 폭이 모자라면 줄바꿈된다.
- 페이지는 저장 상태 칩을 템플릿 툴바의 `statusSlot`으로 넘긴다(문서 모드는 기존 한 줄 구조 유지, 이름에 `min-w-0`).

## 검증

- 단위: `tests/kb/template-dialogs.test.ts`에 2단 구조 회귀 테스트 4건. 관련 suite(kb·studio) 245개 통과, `tsc`(phase 3의 의도된 실패 테스트 제외)·eslint 통과.
- 브라우저(1회용 DB, 390px): 이름 폭 98px, 라벨 48×16 한 줄, 2단 배치, 겹침 0건, 툴바 밖 요소 0건, 가로 스크롤 없음. 데스크톱 폭은 기존과 동일하게 동작.
- 한계: 실제 폰에서의 눈 확인은 에이전트가 하지 못했다(에뮬레이션만). 사용자가 스크린샷으로 문제를 확인했고 수정 후 진행을 승인했다.
