# 02-03: 트리 행 이름 잘림과 버튼 동시 표시 수정

## 증상

- 태블릿~좁은 데스크톱 폭의 왼쪽 문서 트리에서 템플릿·문서 이름이 1~4글자로 잘리고 `이 작품`/`계정` 배지만 보였다. 800px 실측: 행 폭 255px 중 투명(`opacity-0`) 액션 영역이 52~136px를 차지해 이름이 4~15px(필요 폭 52~137px)로 눌렸다.
- 사용자가 추가로 보고: 모바일에서 문서를 하나 탭하면 **모든 행의 버튼**이 처음부터 전부 보여 정신사나웠다.

## 원인

- `kb-tree.tsx` 행: 액션 래퍼가 `ml-auto opacity-0 group-hover:opacity-100`이라 숨겨졌을 때도 레이아웃 폭을 계속 차지했다. 이름에는 `min-w-0 flex-1`, 배지에는 `shrink-0`이 없었다.
- 모든 행이 한꺼번에 보인 이유: 모바일 문서 목록 드로어(`app/studio/[workId]/layout.tsx`)가 `<details class="group ...">`이다. 이름 없는 `group-hover`/`group-focus-within`은 조상 중 아무 `.group`에 반응하므로, 드로어 안에서 문서를 탭해 포커스가 생기면 안의 모든 행이 켜졌다(모바일 프리셋에서 16개 행 표시를 재현).

## 수정

- 이름은 `min-w-0 flex-1 truncate`, 배지·잠금 아이콘·미분류 라벨은 `shrink-0 whitespace-nowrap`.
- 액션 묶음을 `RowActions`로 분리해 레이아웃 밖 오버레이(`absolute inset-y-0 right-1 hidden ...`)로 두었다. 마우스가 있는 환경은 hover/키보드 포커스한 행만, 터치 전용 환경(`hover: none`)은 탭해서 열린(활성) 행만 버튼을 보인다.
- 행 그룹을 이름 그룹 `group/row`로 바꾸고 `group-hover/row`·`group-focus-within/row`만 사용한다. 드로어의 `group-open`(열기/닫기 문구)은 건드리지 않았다.

## 검증

- 단위: `tests/kb/template-tree-ui.test.ts`에 이름 보존·shrink 규칙, 오버레이, 한 행만 표시, 이름 그룹 회귀(드로어 `group`에 반응하지 않음) 테스트 추가, `next/link` mock이 `className`을 전달하도록 수정. 관련 suite 245개 통과.
- 브라우저(1회용 DB): 800px에서 이름 폭 129~187px(가장 긴 이름만 말줄임), 기본 상태 보이는 액션 0개, hover한 행 1개만 5개 버튼 표시. 모바일 프리셋(`hover: none`, `pointer: coarse`)에서 열린 문서 행 1개만 표시, 드로어를 열고 다른 문서를 탭하면 탭한 행으로만 이동(수정 전 16개 행 전부 표시).
- 한계: 실제 터치 기기에서의 동작은 에이전트가 확인하지 못했다(에뮬레이션만).
