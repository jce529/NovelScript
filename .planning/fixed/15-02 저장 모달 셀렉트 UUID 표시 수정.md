# 15-02: 저장 모달 셀렉트 UUID 표시 수정

> Phase 15 `BUG-02`. 원인은 Phase 15-06(`7674e20`)의 저장 확인 모달이다.

## 증상

"문서로 저장하기"로 여는 저장 확인 모달에서 "저장 폴더 변경"과 "템플릿 변경" 셀렉트의 닫힌 상태(트리거)가 "인물 (최상위)"/"인물" 같은 이름이 아니라 `d4cc4c1a-f02c-...` 같은 UUID를 보여줬다. 펼친 목록의 항목은 이름으로 정상 표시됐다.

## 원인

`SaveDocumentPlanModal.tsx`의 두 `<SelectValue />`에 children 렌더 함수가 없었다. 이 프로젝트의 셀렉트는 Base UI(`components/ui/select.tsx`)라서 목록이 열리기 전에는 값에 대응하는 라벨을 알 수 없어 값 문자열을 그대로 그린다. 다른 셀렉트(`AiPanel.tsx`, `QuickAddDialog.tsx` 등)는 라벨을 직접 계산해 넘기고 있었고 이 모달의 두 곳만 빠져 있었다.

## 수정

- 폴더·템플릿 `SelectValue`에 ID를 표시 이름으로 바꾸는 렌더 함수를 추가했다. 목록 항목도 같은 라벨 함수를 사용한다.
- 선택한 ID가 목록에 없으면 `폴더를 선택해주세요`, `템플릿을 선택해주세요`를 표시한다.

## 검증

- `tests/ai/save-document-plan-modal.test.ts`: 초기 표시, 선택 변경 후 표시, 기본 템플릿의 `null` ID, 누락된 ID의 안내 문구. 관련 테스트 22개 통과, `tsc --noEmit` 통과.
- 브라우저 UAT(2026-09-29, 테스트 DB, `localhost:3000`): 모달을 열기 전 트리거가 "인물 (최상위)"/"인물 (기본)"을 표시했다. 폴더를 "서브인물"로, 템플릿을 "기본 인물 템플릿"으로 바꾸면 트리거가 새 이름을 표시했다.
