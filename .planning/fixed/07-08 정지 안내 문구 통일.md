# 07-08: 정지 안내 문구 통일

## 증상
정지된 계정이 쓰기 동작을 하면 스튜디오 저장·좋아요·신고는 "계정 이용이 제한되어 이 작업을 할 수 없어요. 기존 작품과 구매한 회차는 계속 볼 수 있어요."(문구 A)를, 재검토 요청 경로만 "계정 정지로 이 작업을 수행할 수 없습니다."(문구 B)를 보여줬다.

## 원인
07-03에서 쓰기 가드가 문구 A를 반환하도록 만들어 대부분의 경로가 A를 쓰게 됐고, 07-06이 UI-SPEC대로 재검토 요청 경로만 별도 상수 `SUSPENSION_DENIAL_COPY`(B)로 덮어썼다. 두 상수가 따로 정의돼 통일되지 않았다.

## 수정
사용자 결정(2026-10-08)으로 A로 통일했다. `SUSPENSION_DENIAL_COPY`와 `write_suspended` 삼항 분기를 지우고 재검토 요청 경로도 `access.error`를 쓴다. `07-UI-SPEC.md`의 Write denial 행과 대기 todo의 기대 문구도 A로 정정했다.

## 검증
- `tests/admin/user-flows.test.ts` 32건, `tests/admin/sanctions.test.ts` 60건 통과. `SUSPENSION_DENIAL_COPY` 참조 0건.
- 브라우저: 정지 계정(새작가)에서 스튜디오 저장·좋아요·신고가 문구 A로 막힘을 확인(수정 전부터 A). 재검토 요청 경로는 블라인드 콘텐츠가 필요해 브라우저 확인 없이 테스트로 대체.
