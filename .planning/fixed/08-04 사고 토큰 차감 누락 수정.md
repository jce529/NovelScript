# 08-04: 사고 토큰 차감 누락 수정

## 증상

Gemini는 사고(thinking) 토큰을 출력 토큰 요금으로 플랫폼에 과금하지만, NovelScript는 사용자 지갑 차감(`computeDebitAmount`)에 입력+출력 토큰만 반영하고 사고 토큰은 빠뜨리고 있었다. 실제 API 비용이 사용자 청구액보다 커서 플랫폼이 그 차액을 조용히 흡수하는 구조였다.

## 원인

`lib/ai/providers/gemini.ts`의 `mapGeminiResponse`가 `thoughtsTokenCount`를 `usage.thoughtsTokens`로 별도 보고만 하고, `lib/ai/cost.ts`의 `computeDebitAmount`는 이를 전혀 받지 않았다.

## 수정

- `computeDebitAmount`에 `thoughtsTokenCount?: number | null` 파라미터 추가 — `candidatesTokenCount + (thoughtsTokenCount ?? 0)`를 출력 단가로 환산해 합산.
- `lib/ai/chat.ts`가 `result.usage.thoughtsTokens`를 호출부에 전달 (정상 완료·거절 경로가 같은 호출 지점을 공유하므로 두 경로 모두 자동 반영).

## 검증

- `tests/ai/cost-estimate.test.ts`: 사고 토큰 포함/`null` 케이스 추가.
- `tests/ai/chat-idempotency.test.ts`: mock provider로 사고 토큰이 실제 차감액에 반영되는 엔드투엔드 검증 추가.
- `tests/helpers/mock-provider.ts`의 `okResult`에 `thoughtsTokens` 파라미터 추가.
- 오프라인 테스트 174개 통과, `tsc --noEmit` 클린.
