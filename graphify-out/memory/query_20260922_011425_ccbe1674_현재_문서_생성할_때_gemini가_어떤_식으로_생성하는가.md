# Q: 현재 문서 생성할 때 Gemini가 어떤 식으로 생성하는가

## Answer

Expanded via graph vocab: chat, prompt, proposal, document, draft, gemini, save, action. AiPanel의 단일 chatAction이 현재 본문, 대화 기록, 멘션 문서, 장르와 프리셋을 Gemini 3.5 Flash에 보내며, Gemini가 REPLY/DRAFT/DOCUMENT 중 하나를 태그 형식으로 반환한다. DOCUMENT는 category/name/content로 정규식 파싱되고 사용자가 문서로 저장하기를 눌러야 quickAddMentionNode와 saveNodeContent로 영속화된다. 현재 Gemini에는 폴더 트리가 전달되지 않아 저장 위치를 결정하지 않는다.
