| 1. 창업아이템 소개 |
| --- |
| NovelScript는 AI를 창작 보조 도구로 활용하는 웹소설 창작·연재 플랫폼이다. 작가가 멘션(@) 기반으로 특정 장면·캐릭터에 대한 AI 생성을 요청하면, AI가 초안을 제안하고 작가가 이를 검토·수정하여 게시하는 협업형 창작 구조를 제공한다. 개발동기: 생성형 AI 도입 초기 국내외 플랫폼들이 저작권 침해·표절 시비에 지속적으로 노출되며 작가·독자·플랫폼 3자 모두 신뢰를 잃는 사례가 반복되고 있다. NovelScript는 이 신뢰 공백을 선점하여 "책임있는 AI 창작 플랫폼"으로 포지셔닝한다. 핵심기능 멘션 기반 AI 생성 보조 및 챕터 단위 창작 편집기 챕터 단위 유료 열람(토큰 결제) 구조 신고 기반 표시-삭제(Notice-and-Takedown) 절차 3단계 계정 제재(3-Strike) 운영 파운데이션 작가 프로그램(자사 LLM 학습 데이터 제공 옵트인) 수요자 정의 AI 보조 창작 도구를 원하지만 저작권 리스크가 부담스러운 아마추어·세미프로 웹소설 작가 검증된 AI 협업 콘텐츠를 유료로 소비하려는 독자층 |

| 2. 창업아이템 차별성 및 우수성 |
| --- |
| 차별성의 핵심은 "AI 생성물에 대한 법적 책임구조를 제품 설계 단계에서부터 반영했다"는 점이다. 경쟁사(노벨피아, NovelAI)는 이미 존재하나, 실제 시장 공백은 신뢰·수익화 체계의 부재에 있다는 검증 결과를 바탕으로 아래와 같이 대응한다. ① 단계적 API 티어 전략 Phase 1(MVP): Google Gemini API(일반 티어) Phase 2(유료화): Vertex AI Indemnified Services(면책 플랜) 전환 Phase 3(스케일): 멀티모델 라우팅(OpenAI Business, Claude Enterprise 등) ② BYOK(Bring Your Own Key) 화이트리스트 1급: 면책계약이 체결된 API만 허용 2급: 투명성 요건을 충족한 API 3급: 공개 API(제한적 허용) ③ 게시 전 검수 강제 UX + 구상권 이원화 AI 생성물을 검토 없이 즉시 게시할 수 없도록 UX 단계에서 차단 고의적 침해(원작 도용 등)와 무검수 게시(과실)를 구분해 구상권 범위를 차등 적용 ④ 파운데이션 작가 프로그램 완결 여부·인기·품질·무침해 이력 4개 기준을 동시 충족한 작가에게만 자사 LLM 학습 데이터 제공 기회를 옵트인으로 부여 동의 시 토큰 환전 양방향 우대(원화→토큰, 토큰→원화)로 보상 — "아무 글이나 학습하지 않는다"는 신뢰 메시지와 데이터 품질 확보를 동시에 달성 |

| 3. 창업아이템 사업성 |
| --- |
| 시장현황 국내 웹소설 시장은 연 수천억 원 규모로 성장 중이며, AI 생성 보조 도구 도입이 확산되는 추세다. 노벨피아·문피아 등 기존 플랫폼은 AI 기능을 부분 도입했으나 저작권 리스크 관리 체계는 미흡한 상태다. 경쟁사 분석 노벨피아: AI 생성 소설 유통 중심, 리스크 관리 체계 부족 NovelAI: 생성 도구 중심, 유통·수익화 체계 미흡 NovelScript: "생성 + 유통 + 리스크관리 + 수익화"를 통합한 유일한 포지셔닝 리스크 검증 결과의 사업성 반영 "상업 API만 쓰면 저작권 문제가 회피된다"는 통념은 기각됨 — 학습 단계 리스크가 산출(생성물) 단계로 이동할 뿐이며, 일반 상용 API는 책임을 최종 이용자에게 전가하는 구조다. 이에 따라 법무·보험 비용을 초기 사업비에 명시적으로 반영한다(약관 설계, 배상책임보험, 변호사 자문). 국내외 목표시장 1차: 국내 아마추어·세미프로 웹소설 작가 및 독자 2차 확장: 일본·동남아 웹소설 플랫폼 제휴 검토 |

| 4. 창업아이템 사업화 계획 |
| --- |
| SSOT 기반 로드맵 Phase 1~4: Foundation·Studio·Reader·AI Gateway(멘션 기반 생성) 구축 Phase 5: 실제 결제 연동(원화 충전) Phase 6: 유료 챕터 열람(토큰 소모) — 매출 발생 시점, 배상책임보험 가입 시점과 연동 검토 Phase 7: 관리자·모더레이션 도구(신고 처리, 3-Strike 운영) 이용약관 책임구조 (5개 조항) AI 도구 이용 및 결과물 책임 귀속 — 최종 검토·게시 행위는 이용자 본인, 책임도 이용자 귀속 표시-삭제 절차(Notice-and-Takedown) — 신고 접수 → 임시조치(비공개) → 이의제기 → 재게시/삭제 결정 위반 시 계정 제재(3-Strike) — 경고 → 일시정지 → 영구정지 손해배상 및 구상권 — (a)고의적 침해 100% 구상, (b)AI 생성물 무검수 게시는 과실로 보고 구상권 행사(단, 게시 직전 검수 확인 절차 이행을 전제로 함) 회사의 조건부 면책 — 회사가 인식하지 못한 침해에 한해 면책, 고의·중과실은 면책 제외(약관법 제7조 대응) 구상권 행사를 위한 제품(UX) 설계 게시 버튼 클릭 시 "AI 생성 내용을 검토했는지, 타인 저작물과 유사성이 없는지" 확인 모달 + 체크박스 동의 노출 동의 로그(타임스탬프 포함)를 서버에 기록해 구상권 행사 시 증거자료로 활용 파운데이션 작가 프로그램 운영계획 자격요건(동시 충족): 완결작 또는 30화 이상 연재, 누적 조회수 1만 또는 구독 500 이상, 평점 4.0/5.0 이상, 3-Strike 무이력 자격 충족 시 옵트인 동의 요청 → 동의 시 토큰 환전 양방향 우대(원화→토큰 충전 시, 토큰→원화 환전 시) 제공 메인 이용약관과 분리된 별도 특약으로 운영 — 조건·혜택률 변경 시 유연성 확보 동의 철회 시 신규 학습분부터 제외되나, 기존 학습 반영분은 기술적으로 개별 삭제 불가함을 명시 예산 반영 항목 법무 자문비, 배상책임보험료, Vertex AI Indemnified Services 전환 비용, 우대환율에 따른 마진 축소분 추후 확정 사항 토큰 우대환율(α%) 구체 수치 — 재무모델링 후 확정 파운데이션 작가 프로그램 자격 임계치 최종안 원본 대조 코퍼스 확보 여부(라이선스 제휴 vs 신고 기반 축소) — 예산 결정 대기 배상책임보험 가입 시점(Phase 6 매출 발생 시점과 연동) 변호사 자문을 통한 최종 약관 문구 검증(구상권·면책 조항 중심) |
