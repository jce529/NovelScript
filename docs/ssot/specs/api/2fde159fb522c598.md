# POST /auth/complete-email#action:submitEmail

submitEmail reads `email` from `FormData`, trims it, rejects missing or non-`@` values with a redirect to `/auth/complete-email?error=invalid`, then creates a Supabase client and calls `supabase.auth.updateUser({ email })`; if that call returns an error, it redirects back to `/auth/complete-email?error=<encoded message>`, otherwise it redirects to `/account`. The page component renders the email form, shows any `error` search param, and submits the form to `submitEmail`.
