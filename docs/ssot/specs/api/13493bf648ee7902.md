# POST /write/start#action:submitWriterUpgrade

Authenticated form action on `/write/start` that reads `penName` and `bio` from `FormData`, calls `upgradeToWriter(supabase, { userId, penName, bio })`, and redirects either to `/login`, back to `/write/start?error=...`, or to `/account` depending on the observed auth and upgrade result. The related page renders the writer-start form, shows the `error` search param, and posts the form to `submitWriterUpgrade`.
