# POST /account#action:deleteAccountAction

deleteAccountAction creates a Supabase server client, reads the current user with supabase.auth.getUser(), redirects to /login when no user is present, creates an admin client, soft-deletes the current user's profile through softDeleteAccount(admin, user.id), signs the user out with supabase.auth.signOut(), and redirects to /login again after the mutation. The visible side effect is a profiles update that clears pen_name_bio and sets deleted_at when the row is still active.
