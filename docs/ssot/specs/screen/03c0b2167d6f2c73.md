# AccountPage / account

Account settings screen for the signed-in user. It loads the current user and profile from Supabase, redirects unauthenticated or inactive accounts to /login, shows email, shows pen name only for writer profiles, links non-writers to /write/start, and submits account deletion through deleteAccountAction.
