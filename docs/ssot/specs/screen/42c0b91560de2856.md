# HomePage

Route `/` renders the main discovery home screen with a site header, promo banner, optional recently read section for signed-in users, weekly ranking filters, and either an empty state or a grid of feed cards. The screen reads `searchParams`, loads the current Supabase user, fetches feed rows through `listFeed`, and conditionally fetches `listRecentlyRead` for the signed-in user.
