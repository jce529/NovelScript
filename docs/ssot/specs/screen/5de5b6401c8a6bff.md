# Write Start

Authenticated write-start screen that lets a reader begin writer onboarding by entering a pen name and optional bio, then submitting an upgrade action. If the user is not signed in, the page redirects to /login. Submission either redirects to /account on success or returns to /write/start with an error query parameter that is rendered inline.
