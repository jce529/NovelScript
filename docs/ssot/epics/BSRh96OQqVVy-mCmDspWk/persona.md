# Chapter Planning and Structure

Persona vocabulary for writers who create, open, and reorder chapters within a work.

## Actors

- Writer
  - description: A person working on a work who creates chapters, reviews the chapter list, opens a chapter, and adjusts chapter order.
  - aliases: author
  - aliases: user
  - typicalActions: Create a new chapter for the current work.
  - typicalActions: Open an existing chapter from the chapter list.
  - typicalActions: Reorder chapters to match the intended structure.
- Chapter list viewer
  - description: A person viewing the chapter list for a work and navigating between chapters.
  - aliases: chapters page user
  - typicalActions: Review the list of chapters for a work.
  - typicalActions: Select a chapter to open it.
  - typicalActions: Start creating a new chapter from the chapter list.

## Evidence Gaps

- The available context identifies chapter creation, chapter listing, chapter opening, and drag-and-drop reordering, but it does not describe any other user types for this epic.
- The context does not confirm whether chapter ordering is limited to the current work view or whether it persists across other views.
- The context does not state any permissions, collaboration rules, or ownership semantics for chapter actions.
