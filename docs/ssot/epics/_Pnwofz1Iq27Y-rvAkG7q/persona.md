# Work Workspace Persona

An authenticated writer uses the work workspace as a home base to review the current work, read its core details, and move into chapter editing.

## Actors

- Authenticated writer
  - description: A person who is signed in and views their own work workspace to review the work record and continue editing.
  - aliases: writer
  - aliases: signed-in user
  - typicalActions: Open the work workspace
  - typicalActions: Review the work title and synopsis
  - typicalActions: Follow the link to the chapter list
  - typicalActions: Continue into editing tasks

## Evidence Gaps

- It is not confirmed whether unauthenticated access is blocked or redirected for this workspace.
- It is not confirmed whether the workspace supports any actions beyond viewing work details and navigating to chapters.
