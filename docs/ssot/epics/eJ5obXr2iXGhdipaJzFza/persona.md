# Story Knowledge Management personas

A writer-focused persona for maintaining reusable story knowledge in a node-based editor, including editing and saving reference content for consistent storytelling.

## Actors

- Writer
  - description: A person who maintains reusable story knowledge inside the editor for a work.
  - aliases: editor
  - aliases: authenticated user
  - typicalActions: Open a knowledge-base node
  - typicalActions: Edit the node text
  - typicalActions: Save changes to the document
  - typicalActions: Review success or error feedback after saving

## Evidence Gaps

- Only one screen specification was provided, so additional personas for this epic are not confirmed.
- The available context confirms editing and saving behavior for a knowledge-base node, but it does not confirm broader workflows beyond that screen.
