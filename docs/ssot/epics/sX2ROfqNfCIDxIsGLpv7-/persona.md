# Work Detail and Engagement Personas

This epic centers on readers who view a work detail page, inspect its overview content, and use engagement actions such as liking or reporting when signed in.

## Actors

- Reader
  - description: A person who opens a work detail page to review the work and navigate its sections.
  - aliases: viewer
  - aliases: browser
  - typicalActions: Open the work detail page
  - typicalActions: Read the overview and supporting sections
  - typicalActions: Move between the available tabs
  - typicalActions: Use the back navigation to return to the prior page
- Signed-in reader
  - description: A reader with an active signed-in state who can perform engagement actions on the work detail page.
  - aliases: authenticated reader
  - aliases: logged-in reader
  - typicalActions: Like a work
  - typicalActions: Report a work
  - typicalActions: Review the work detail content before engaging

## Evidence Gaps

- The provided context confirms the work detail screen and its engagement actions, but it does not describe additional audience segments beyond readers and signed-in users.
- The context does not confirm whether reporting is available to every viewer or only to authenticated users on all variants.
