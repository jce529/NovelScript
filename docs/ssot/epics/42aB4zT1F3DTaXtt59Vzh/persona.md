# New Work Creation Personas

A compact persona vocabulary for the new work creation flow, centered on the person who creates a new work by entering core metadata and submitting the form.

## Actors

- Authenticated creator
  - description: A signed-in person who starts a new work record by opening the creation form, entering the required title, and optionally adding synopsis and genre information.
  - aliases: creator
  - aliases: signed-in user
  - typicalActions: Open the new work form
  - typicalActions: Enter a title for the work
  - typicalActions: Optionally add a synopsis
  - typicalActions: Optionally choose a genre
  - typicalActions: Submit the form to create the work
  - typicalActions: Continue to the newly created work page after success
