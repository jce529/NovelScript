본 문서는 작가가 AI를 완벽하게 제어하며 세계관을 구축하고, 연재 현황과 수익(토큰)을 관리하는 독립된 창작 전용 대시보드 및 웹 IDE 환경을 정의한다. (※ 집필 공간(Studio)과 에셋 스토어는 독자 공간과 구분되는 별도 서브도메인으로 함께 묶어 운영하며, 세션과 토큰 잔액은 전체 플랫폼에서 공유된다.)

### 1. 작가 대시보드 (Studio Home)

작가의 프로젝트 관리와 플랫폼 내 경제 활동을 통합 관리하는 베이스캠프 화면이다.

- **프로젝트 관리 (Work Management):**
    
    - 진행 중인 작품 리스트를 썸네일과 그리드 형태로 제공하며, 최신 연재 회차 및 업데이트 일자를 표시한다.
        
- **통계 인스펙터 (Analytics):**
    
    - 각 회차별 '스크롤 심도 완독률'과 '이탈 구간'을 꺾은선 그래프로 시각화하여, 독자가 어느 지점에서 흥미를 잃었는지 데이터 기반으로 분석할 수 있게 돕는다.
        
- **경제 관리 (DevEx & Token Center):**
    
    - 보유한 '노벨 토큰' 잔액을 실시간으로 표시한다.
        
    - `[토큰 충전(결제)]`, `[현금 환전(Cash-out)]`, `[외부 API 키(BYOK) 등록/관리]` 메뉴를 한곳에 배치하여 자본의 선순환과 재투자를 직관적으로 유도한다.
        

### 2. 웹 에디터 (Web IDE) - 3단 분할 캔버스

창작의 흐름(Flow)이 끊기지 않도록 좌-중-우 패널이 로컬 메모리(Zustand) 기반으로 지연 없이(Zero-Latency) 상호작용하는 핵심 작업 공간이다.

#### A. 좌측 패널: 지식 베이스 & 파일 탐색기

작품의 뼈대인 설정집과 원고를 관리하는 공간.

- **마크다운 트리:** 인물, 장소, 사건, 세력, 아이템 등의 템플릿 문서가 폴더 계층 구조로 나열되며, 드래그 앤 드롭으로 관리한다.
    
- **원고 리스트:** 작성 중인 본문 회차(1화, 2화...) 목록을 하단에 배치한다.
    

#### B. 중앙 패널: 메인 집필 캔버스

실제 소설을 작성하고 AI의 결과물과 호흡하는 메인 에디터.

- **인메모리 멘션 (`@`):** 텍스트 작성 중 `@` 입력 시 좌측 패널의 설정 문서 목록이 자동 완성 드롭다운으로 나타난다.
    
- **💡 퀵 애드 (Quick Add UX):** 드롭다운 목록에 없는 새로운 고유명사 타이핑 시, 하단에 `[+ 새 문서 만들기]` 버튼이 활성화된다. 클릭 시 화면 전환 없이 가벼운 오버레이 팝업이 떠서 즉석에서 설정을 추가하고 바로 본문 작성으로 복귀할 수 있다.
    
- **실시간 어시스트 (Ghost Text):** 작가의 타이핑이 일정 시간 멈추면(Debouncing), AI가 문맥을 읽고 흐릿한 회색 텍스트로 다음 문장을 제안하며 `Tab` 키로 수락한다.
    

#### C. 우측 패널: AI 코워커 & 프롬프트 컨트롤러

AI의 컨텍스트(기억)와 토큰 소모량을 실시간으로 통제하며 대화를 나누는 대시보드. 복잡한 설정은 숨기고 직관적인 인터페이스를 제공한다.

- **상단: 프리셋 선택기 & 설정(⚙️)**
    
    - **프리셋 드롭다운:** 우측 상단의 작은 영역에서 `[🔰 초보자형]`, `[⚡ 중급자형]`, `[🔥 자유형]` 프리셋을 원클릭으로 전환할 수 있다.
        
    - **⚙️ 시스템 프롬프트 설정 (톱니바퀴 버튼):**
        
        - 이 버튼을 누르면 화면 중앙에 쾌적한 크기의 [시스템 설정 모달창]이 열린다.
            
        - 여기서 작가는 "하드보일드 문체 적용", "고어한 전투 묘사 강조" 등 본인만의 문체나 글로벌 지시어(시스템 프롬프트)를 세팅하고 저장할 수 있다. (중급/자유형 프리셋 선택 시 활성화)
            
- **중단: 컨텍스트 인벤토리 및 채팅창**
    
    - **컨텍스트 칩:** 중앙 캔버스에서 멘션된 문서들이 칩(Chip) 형태로 노출되며(`[주인공 ✕]`), 명시적으로 칩을 삭제해 AI의 기억에서 제외할 수 있다.
        
    - **AI 채팅 인터페이스:**
        
        - 초보자형을 선택한 경우, 채팅창 하단에 현재 문맥(본문)에 맞는 '다이내믹 추천 프롬프트 칩(예: 💬 갈등 심화시키기)'이 동적으로 표시되어 빠른 명령을 돕는다.
            
- **하단: 토큰/비용 게이지 바**
    
    - 현재 컨텍스트에 담긴 데이터양(관계 지역성 가중치 포함)을 계산하여, 1회 AI 호출 시 예상 소모 토큰량을 초록~빨강 게이지로 시각화한다.
