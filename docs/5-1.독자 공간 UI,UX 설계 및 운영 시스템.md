본 문서는 독자가 가짜 양산형 글에 피로를 느끼지 않고 진짜 재미있는 작품을 발굴하며, 서사에 온전히 몰입할 수 있도록 설계된 '독자용 프론트 스토어'의 인터페이스와 백그라운드 운영 로직을 정의한다.

### 1. 플랫폼 메인 홈 (Discovery)

철저히 데이터(완독/연독)와 독자 리뷰 중심으로 큐레이션 되어 탐색 피로도를 최소화하는 첫 화면이다. (완독률/연독률 산출 알고리즘 상세는 [[4. 시스템 아키텍처 및 기술 스택]] 4.3절 참조)

- **실시간 랭킹 (Trending Now):** 단순 조회수(클릭)가 아닌 '스크롤 심도 기반 완독률'과 '연독률' 점수를 합산하여 줄 세운 진짜 랭킹 보드. 작품 썸네일 우측 상단에 `연독률 92%` 등의 신뢰도 높은 배지를 부착한다.
    
- **명예의 전당 (우수 리뷰 매거진):** 일반 댓글 창이 아닌, 퀄리티 높은 독자 리뷰(요약, 감상평, 텍스트 발췌)를 카드 뉴스나 매거진 형태로 크게 노출한다. 도파민을 자극하는 하이라이트를 보여주되, 버튼은 `[이 하이라이트부터 읽기]`가 아닌 **`[1화부터 정주행하기]`** 또는 `[해당 에피소드 시작(예: 15화)부터 읽기]`로 배치하여 소설 특유의 서사 빌드업을 해치지 않도록 유도한다.
    
- **루키 쿼터존 (최소 10화 검증):** 1~3화 수준의 낚시성 양산작을 걸러내기 위해, **최소 10화(또는 누적 5만 자) 이상** 연재된 신작만 메인 홈 노출 쿼터(기본 트래픽)를 부여받는 전용 큐레이션 구역이다.
    

### 2. 작품 상세 페이지 (Novel Detail)

작품 진입 시 결제(토큰)를 유도하고 세계관 몰입을 돕는 4분할 탭 구조이다.

- **메타 헤더:** 거대한 배경 썸네일, 제목, 작가명, 누적 완독/연독 지표 노출. 어그로성 낚시 글이나 내용 붕괴를 독자가 3초 만에 알릴 수 있는 직관적인 **`[🚨 내용 불일치/표절 신고]`** 버튼을 상단에 고정 배치한다.
    
- **[소개] 및 [회차] 탭:** 작가 공식 줄거리 및 우수 리뷰 모아보기 영역, 그리고 유·무료 회차 리스트와 토큰 결제 UI를 제공한다.
    
- **[세계관 (Lore/Wiki)] 탭:** 작가가 공개(Opt-in)한 설정 문서(장소, 인물, 사건 등)를 위키백과 형태로 제공한다.
    
    - **AI 시각화 에셋:** 단순 텍스트를 넘어, 작가의 묘사를 바탕으로 자동 생성된 인물/장소 일러스트 이미지가 텍스트와 함께 노출되어 시각적 이해를 돕는다.
        
    - **진도별 스포일러 자동 잠금:** 작가가 설정 템플릿에 기입한 발생회차 메타데이터를 활용하여, 독자의 현재 열람 진도를 초과하는 스포일러 정보는 자동으로 까만 줄(Redacted) 처리되거나 `🔒 [O화 열람 시 해제]` 형태로 가려진다.
        

### 3. 웹소설 뷰어 (Viewer)

가독성과 다음 화 결제 유도에만 집중하는 클린 리딩 공간이다.

- **인터페이스:** 인터랙티브 툴팁은 모두 상세 페이지(세계관 탭)로 분리하고, 뷰어 내부는 다크 모드, 폰트 조절, 스크롤/페이징 기능만 제공하여 활자에만 집중하게 한다.
    
- **스크롤 심도 트래커 (백그라운드):** 유저의 스크롤 속도와 위치를 감지하여 '방치형 허수 체류'나 '광클 스킵'을 걸러내고, 유효한 속도로 하단에 도달했을 때만 DB에 유효 완독 1스택을 전송한다.
    
- **바텀 시트 (Bottom Action):** 스크롤이 맨 하단에 닿으면 `[다음 화 보기 (10 토큰)]`, `[우수 리뷰 작성하기]` 버튼이 팝업된다.
    

### 4. 서버 측 AI 사전 검수 및 운영 시스템

저비용 고효율의 읽기(Input) 토큰을 활용해 플랫폼의 자정 작용을 돕는 방역 파이프라인이다. (인프라 구성, 검증 로직, 3-Strike 제재 흐름의 상세 스펙은 [[4. 시스템 아키텍처 및 기술 스택]] 4.3절 참조)

- **비동기 자동 검수 큐:** 작가가 원고를 업로드하면, 백그라운드 경량 모델(SLM)이 전체 텍스트를 판독하여 **1) 시놉시스-본문 내용 정합성**, **2) 기존 IP 고유명사/설정 표절 여부**를 1차 필터링한다.
    
- **블라인드 로그 및 휴먼 리뷰 (3-Strike Out):**
    
    - AI 검수에서 이상 징후가 발견되거나 독자 신고가 누적되면 해당 회차는 즉시 노출이 차단(Blind)되며, 계정에 '위반 의심 로그'로 남는다.
        
    - 이 로그는 운영 직원의 대시보드로 이관되며, 직원이 직접 검토 후 오탐지일 경우 해제, 실제 위반일 경우 '확정 패널티'로 전환한다.
        
    - 미해결 로그 및 확정 패널티가 일정 수치를 초과하면 계정 정지 등의 자동 제재가 이루어진다.
