### 2.1. 마크다운(MD) 기반 지식 베이스 (Knowledge Base)

창작자가 작품의 뼈대를 구축하고 AI에게 학습시킬 문맥을 관리하는 공간이다.

- **기본 템플릿 제공:** 세계관 구축에 필수적인 5대 요소(장소, 사건, 세력, 아이템, 인물)에 대한 마크다운 폼을 제공한다.
    
- **자유도 보장:** 유저는 템플릿의 서식을 자유롭게 수정 및 확장할 수 있으며, 자신만의 커스텀 템플릿을 생성할 수 있다.
    
- **위키 링킹(Wiki Linking):** 문서 내에서 `[[인물A]]`, `[[사건 링크]]` 등의 양방향 링크 문법을 지원하여, 복잡한 설정 간의 관계를 네트워크로 연결하고 시각화(Graph View)한다.
    

### 2.2. 다중 멘션(@) 기반 다이내믹 컨텍스트 주입 (Dynamic Context Injection)

노벨스크립트의 핵심 킬러 피처로, 작가가 직접 AI의 컨텍스트 윈도우와 토큰 소모량을 통제하는 시스템이다.

- **다중 멘션 지원:** 본문 에디터에서 `@`를 입력해 설정집 내의 다수 문서를 동시에 호출할 수 있다. (예: `@인물A`와 `@아이템B` 동시 멘션)
    
- **토큰 및 퀄리티 컨트롤:** 중급자 이상의 창작자는 불필요한 설정 주입을 배제하고 씬(Scene)에 필요한 멘션만 선별적으로 조합하여, API 토큰 비용을 최소화함과 동시에 AI의 연산 집중도를 높여 고품질의 텍스트를 유도한다.
    
- **프롬프트 래핑 (Prompt Wrapping):** 멘션된 마크다운 문서들은 백엔드에서 자동으로 취합되어, 유저의 본문 작성 지시어와 함께 시스템 프롬프트로 병합(Wrapping)된 후 LLM API로 전송된다.
    

### 2.3. 실시간 비용/토큰 모니터링 데시보드

자체 정액 토큰 사용자 및 BYOK(자체 API 키) 사용자 모두에게 투명한 비용 관리를 제공한다.

- **토큰 게이지 바:** 멘션된 문서의 텍스트 양에 비례하여 1회 생성(API 호출) 시 소모될 예상 토큰량을 에디터 하단에 시각적으로 표시한다.
    
- **최적화 알림:** 멘션된 문서가 너무 방대하여 허용 컨텍스트를 초과하거나 비용 효율이 떨어질 경우, 경고 UI를 통해 작가의 수동 최적화를 유도한다.
    

### 2.4. 비동기 자동 필터링 및 퀄리티 컨트롤 (Async Quality Control)

양산형 텍스트와 어그로성 낚시 글을 걸러내는 플랫폼 자정 시스템이다. (파이프라인 구성, 표절 검증, 3-Strike 제재 체계 등 상세 스펙은 [[4. 시스템 아키텍처 및 기술 스택]] 4.3절 참조)

- **경량 모델(SLM/LLM) 큐잉:** 유저가 원고를 등록(Submit)하면 즉시 노출되지 않고 대기(Pending) 상태로 전환되며, 백그라운드 큐에서 경량화 모델이 검수를 진행한다.
    
- **시놉시스-본문 일치 검증:** 유저가 제출한 하이라이트/시놉시스와 본문의 내용이 일치하는지 판별하여, 일치 시 메인 노출 승인, 불일치 시 '보류(Hold)' 처리 후 관리자 대시보드로 이관한다.
    

### 2.5. 듀얼 과금 및 BYOK 연동 모듈

- **자체 토큰 결제 시스템:** 플랫폼 내에서 결제 및 구독을 통해 충전된 토큰을 소모하는 로직.
    
- **API Key Vault:** 유저가 입력한 외부 API 키를 암호화하여 DB에 안전하게 보관하고, 호출 시에만 복호화하여 사용하는 보안 모듈.
    

여기까지가 시스템이 작동하는 핵심 기능입니다. 작가들의 창작 환경(IDE)은 굉장히 촘촘하게 설계가 된 것 같습니다.
