# 세계관 잡다 메모 (정리 안 됨)

화폐 단위는 "은닢". 빵 한 덩이가 3닢, 용병 하루 품삯이 20닢.

종교는 두 갈래: 불꽃을 섬기는 "재의 교회"와 서리를 섬기는 "북방 신앙". 재의 교회 사제는 회색 두건. 이름이 재의 검과 겹치는 건 우연 아님, 검을 만든 대장장이가 원래 교회 소속이었음.

북부 해안에서는 해마다 첫눈 오는 날 "종 울림 축제"를 한다. 안개 늪의 종소리 전설이 여기서 시작됨.

- 마법은 없음. 대신 재의 검처럼 "전승이 깃든 물건"만 존재
- 왕은 현재 병상. 왕세자파 vs 왕비파 대립 (3부에서 본격화)
- 바르톨로가 도박 빚이 있다는 설정 추가 예정
