같은 세계관(잿빛 왕국)을 두 가지 형태로 쓴 세트예요. 사이드바 "파일 올리기" → "AI 자동 분류"로 올려 비교하세요.

Jev가 구분하기 쉬운 경우. 프론트매터 `tags`와 템플릿 소제목이 그대로 있어요.

| 파일 | 기대 분류 |
| --- | --- |
| 레온하르트.md | 인물 |
| 안개 늪.md | 장소 |
| 안개 늪 매복전.md | 사건 |
| 서리 기사단.md | 세력 |
| 재의 검.md | 아이템 |

## 비정형 (템플릿 없음) — `비정형/` 5개
자유 메모. 프론트매터·소제목 없이 서술형이고, 일부는 여러 종류가 섞여 있어요.

| 파일 | 기대 분류(정답이 하나는 아닌 것 포함) |
| --- | --- |
| 이사벨 메모.txt | 인물 |
| 북쪽 관문 구상.md | 장소 (사건 언급이 섞임) |
| 검은 연맹 아이디어.md | 세력 |
| 잿빛 성채 그날 밤.txt | 사건 (회상 초안, 인물·장소 언급 많음) |
| 세계관 잡다 메모.md | 애매함 — 분류 불확실 시 직접 배치 안내가 뜨는지 확인 |

확인 포인트: 정형은 자동 제안이 전부 맞는지, 비정형은 어디서 틀리거나 "확신하지 못했어요" 경고가 뜨는지.
