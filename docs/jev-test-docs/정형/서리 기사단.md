# 🛡️ 서리 기사단

## 📌 기본 정보
- **설립 목적 및 이념**: 북부 국경을 지키고, 왕국이 외면한 난민을 보호하는 것.
- **세력 규모 및 특징**: 약 300명의 소수 정예. 자금은 부족하지만 기동력과 결속이 강하다.
- **지도자**: [[아델]] (현재 단장, 3대)
