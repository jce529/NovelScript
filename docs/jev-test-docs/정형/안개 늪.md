# 🗺️ 안개 늪

## 📌 기본 정보
- **위치**: 북부 대륙, [[잿빛 성채]]에서 남쪽으로 이틀 거리의 저지대
- **통치 세력 / 지배자**: 무법지대 (가끔 [[검은 연맹]] 정찰대가 출몰)
- **장소의 특성**: 1년 내내 짙은 안개가 끼고, 늪 가스에 중독될 위험이 있다. 해가 져도 길을 잃기 쉽다.

## 👁️ 외형 및 묘사
- **전체적인 풍경**: 물빛이 탁한 갈색이고 마른 나무 뿌리가 수면 위로 솟아 있다. 멀리서 종소리가 들린다.
- **주요 랜드마크**: 반쯤 가라앉은 옛 종탑, 안개 속에 서 있는 돌 이정표

## 📦 획득 가능한 아이템 (특산물)
- [[서리 이끼]]: 종탑 북쪽 바위틈에서 자란다. 해독제 재료.
- (기타: 늪 가스를 걸러 주는 갈대 마스크 재료)

## 얽힌 서사 (스토리)
- **장소와 연관된 인물**:
  - **거주자/토착민**: 늪지기 노인 [[오르카]]
  - **방문자 (거쳐가는 인물)**: [[레온하르트]] 일행 (남쪽 항구로 가는 지름길로 통과)
- **장소에서 일어나는 사건**:
  - [[안개 늪 매복전]]: 12화~15화, 일행이 연맹 정찰대와 교전
