## 📌 사건 개요
- **배경 (장소 및 시점)**: [[안개 늪]] / 12화~15화
- **발생 원인 (발단)**: 레온하르트 일행이 지름길로 늪을 택했고, 연맹이 이를 미리 알고 매복했다. 일행 내부에 정보를 흘린 자가 있다는 의심이 생긴다.

## 👥 얽힌 인물 및 사물
- **참여 인물**:
  - **주역**: [[레온하르트]] (일행을 살려 늪을 빠져나가려 함)
  - **조연**: [[바르톨로]] (후미를 맡다 다리에 부상)
- **핵심 아이템 및 단서**: [[재의 검]] (안개 속에서 붉게 달아올라 위치를 노출시킴)

## ⏳ 전개 타임라인
- [x] **도입**: 일행이 늪 입구에서 종소리를 듣고 길을 잃는다
- [x] **전개**: 연맹 궁수가 양쪽 둑에서 화살을 쏟아낸다
- [x] **위기/절정**: 재의 검이 각성하며 안개를 태워 시야가 열린다
- [x] **결말**: 일행이 연맹 정찰대를 물리치고, 쓰러진 정찰병에게서 배신자의 인장 반지를 얻는다

## 🦋 사건의 여파 (나비효과)
- **인물의 변화**:
  - [[레온하르트]]: 동료 중 누구도 완전히 믿지 못하게 됨
- **다음 사건으로의 연결**:
  - 인장 반지의 주인을 추적하다 [[왕도 잠입 사건]]으로 이어짐
