# ⚔️ 재의 검

## 📌 기본 정보
- **기원과 가치**: 잿빛 성채의 대장장이가 왕가의 요청으로 만든 한 쌍 중 하나. 세계에 남은 유일한 한 자루로 취급된다.
- **외형 및 상태 묘사**:
  - **평상시**: 재처럼 탁한 회색 칼날, 손잡이는 낡은 가죽
  - **개방/발동 시**: 칼날이 붉게 달아오르고 주변에 열기와 연기가 퍼진다

## ✨ 능력과 한계
- **주요 능력**: 안개와 연기를 태워 시야를 틔우고, 칼날에 닿은 거짓말을 태운다는 전승이 있다.
- **제약 및 페널티 (리스크)**: 발동할 때마다 사용자의 체온이 떨어진다. 연달아 쓰면 기절할 수 있다.
