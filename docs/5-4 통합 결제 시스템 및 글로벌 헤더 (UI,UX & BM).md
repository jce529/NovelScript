본 문서는 독자 공간(Reader Space), 집필 공간(Studio), 에셋 스토어(Asset Store) 전체를 관통하는 글로벌 네비게이션과 듀얼 트랙 토큰 비즈니스 모델을 정의한다.

**도메인 구조:** 독자 공간은 메인 도메인에서 서비스되며, 집필 공간(Studio)과 에셋 스토어는 별도 서브도메인으로 함께 묶여 운영된다. 세 공간 모두 동일한 세션과 토큰 잔액을 실시간 공유하므로, GNB의 토큰 잔액·장바구니·프로필 상태는 도메인 이동과 무관하게 항상 동기화되어 노출된다.

### 1. 글로벌 네비게이션 바 (GNB) 공통 UI

유저가 플랫폼의 어느 공간에 있든 자신의 자산(토큰)을 직관적으로 확인하고 충전할 수 있도록 최상단 헤더를 고정(Sticky)한다.

- **좌측:** 플랫폼 로고 및 공간 이동 메뉴 (독자 홈 / 내 스튜디오 / 에셋 스토어)
    
- **우측 (개인화 영역):**
    
    - **🛒 장바구니 (에셋 스토어 전용):** 에셋 스토어 탭에 있을 때만 활성화된다. 클릭 시 우측 슬라이드 패널로 담아둔 에셋 모듈과 총 결제 예정 토큰이 표시된다.
        
    - **🪙 토큰 잔액 및 충전 `[ 1,500 ⓣ | ➕ ]`:** 현재 보유한 토큰 숫자가 상시 노출되며, 옆의 `+` 버튼을 누르면 즉시 화면 중앙에 [토큰 충전소 모달]이 팝업된다.
        
    - **👤 유저 프로필:** 마이페이지, 결제 내역, 로그아웃 등의 기본 메뉴 제공.
        

### 2. 장바구니 및 구매 액션 분리 (에셋 스토어 & 뷰어)

유저의 구매 목적(쇼핑 vs 즉시 열람)에 따라 구매 동선을 이원화하여 결제 마찰을 최소화한다.

- **장바구니 담기 (Add to Cart):**
    
    - **대상:** 에셋 스토어에서 여러 작가의 세계관 팩이나 프롬프트 모듈을 이것저것 조합해서 쇼핑할 때 사용.
        
    - **플로우:** 원하는 모듈을 체크한 뒤 `[장바구니 담기]`를 누르면, 우측 상단 장바구니 아이콘에 `N` 뱃지가 뜬다. 이후 장바구니 페이지에서 전체 모듈을 일괄 결제(Batch Purchase)할 수 있다.
        
- **바로 구매하기 (1-Click Buy Now):**
    
    - **대상:** 에셋 스토어에서의 충동구매, 또는 **웹소설 뷰어에서의 유료 회차 열람**.
        
    - **플로우:** 과정 생략 후 즉시 유저의 토큰 잔액을 차감한다. (잔액 부족 시 `[토큰 충전소]`로 자동 라우팅). 특히 독자가 뷰어 하단에서 `[다음 화 보기 (10 토큰)]`를 눌렀을 때 흐름이 끊기지 않도록 즉각적으로 다음 화 텍스트를 렌더링한다.
        

### 3. 비즈니스 모델 (BM): 듀얼 트랙 토큰 경제

토큰의 획득 경로를 '구독제'와 '단건 충전' 두 가지로 나누어 플랫폼 수익성을 극대화한다. 두 경로 모두 '현금→토큰' 충전이므로 3. 비즈니스 모델 및 사용자 정책 문서의 환전 수수료 정책(충전/환전 양방향 수수료)이 동일하게 적용된다.

- **A. 월정액 구독제 (Subscription - 예: NovelScript Pro):**
    
    - **구조:** 매월 정기 결제(예: 9,900원) 시, 독자/작가 모두에게 유용한 혜택과 '기본 지급 토큰(예: 매월 1,000 토큰)'을 제공한다.
        
    - **혜택 예시:** 프리미엄 AI 모델(예: 더 무겁고 똑똑한 모델) 호출 권한, 뷰어 내 설정집 이미지 팝업(로어 탭) 열람 무제한 등의 구독자 전용 편의 기능을 묶어 판다.
        
    - **BYOK 전용 플랜:** 이미 외부 API 키를 보유해 AI 추론 비용을 자체 부담하는 BYOK 유저를 위해, 일반 구독제보다 저렴한 가격에 제한된 토큰(플랫폼 편의 기능 이용 및 소량의 자체 모델 호출용)만 제공하는 별도 요금제를 둔다.
        
- **B. 일반 토큰 충전 (A La Carte):**
    
    - **구조:** 묶음 단위로 토큰을 개별 구매하는 상점 기능이다. (예: 100 토큰 = 1,000원 / 550 토큰 = 5,000원).
        
    - **목적:** 구독제 기본 토큰을 모두 소진한 상태에서 고가의 에셋 팩을 구매하거나, 특정 작가에게 대량의 후원(도네이션)을 하고 싶을 때 상단 헤더의 `+` 버튼을 통해 즉시 충전할 수 있게 지원한다.
