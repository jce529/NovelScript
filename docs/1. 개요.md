## 1. 서비스 개요 (Product Overview)

본 서비스는 생성형 AI(LLM)를 단순한 '자동 글쓰기 기계'가 아닌, 작가의 창작을 돕고 독자의 몰입을 극대화하는 '웹소설 전용 통합 창작 환경(IDE)'이자 '인터랙티브 콘텐츠 플랫폼'이다.

창작자는 복잡한 웹 에디터 환경에서 플랫폼 자체 정액 토큰(월 구독/종량제 충전)을 사용하거나, 개인의 외부 API 키(BYOK)를 직접 연동해 고성능 모델을 제어할 수 있다. 특히 3단계 창작 프리셋과 멘션(`@`) 기능을 통해 설정 붕괴 없이 고품질 원고를 모듈화하여 생산하며, 독자는 세밀한 큐레이션 환경에서 양질의 스토리를 소비하게 된다.

## 2. 서비스 비전 (Product Vision)

> "프롬프트가 문학이 되는 공간. 작가에게는 완벽한 통제력을, 독자에게는 검증된 도파민을 제공하는 차세대 웹소설 플레이그라운드."

기존 AI 소설 플랫폼이 직면한 '양적 팽창에 따른 질적 하락'과 '서버 인프라 비용의 늪'을 기술적으로 해결한다. 진입장벽을 낮춘 토큰제와 헤비 유저를 위한 BYOK가 공존하는 듀얼 과금 생태계를 제공하여 작가와 독자 모두에게 지속 가능한 웹소설 창작 환경을 구축한다.

## 3. 배경 및 문제 정의 (Problem Statement)

- **창작 및 운영 비용의 딜레마:** 플랫폼이 모든 AI 추론 비용을 일괄 부담하는 단순 무제한 정액제는 헤비 유저로 인한 인프라 적자를 피할 수 없다. 반면, API 키 연동(BYOK)만을 강제하면 일반 창작자의 진입장벽이 극도로 높아진다.
    
- **AI 산출물의 품질 한계:** 롱 컨텍스트 환경에서도 AI는 장기 연재 시 설정 충돌(Hallucination)을 일으키며, 웹소설 특유의 완급 조절에 실패해 유료 결제 전환율이 극히 낮다.
    
- **콘텐츠 발견의 피로도(Discovery Fatigue):** 무분별한 AI 양산 글이 쏟아지는 환경에서, 독자는 양질의 작품을 찾기 전에 탐색을 포기하고 이탈한다.
    
- **저작권 리스크:** 유저의 악의적이거나 무작위적인 프롬프트로 인해 기존 유명 IP가 표절될 경우, 플랫폼이 치명적인 법적 분쟁에 휘말릴 수 있다.
    

## 4. 해결 방안 및 핵심 가치 (Solution & Core Value)

### 4.1. 듀얼 인프라 및 과금 체계 (BYOK + 정액 토큰제)

- **초심자/일반 유저:** 복잡한 개발자 콘솔 설정 없이 플랫폼 내에서 **월간 정액 구독(기본 토큰 지급)** 또는 **토큰 종량제 충전**을 통해 즉시 창작에 참여한다.
    
- **헤비/전문 유저:** 개인의 외부 API 키(BYOK)를 직접 등록하여 토큰 한도 제한 없이 고성능 모델을 마음껏 활용하며, 플랫폼은 서버 연산 비용 부담을 최소화한다. 이미 자체 API 비용을 부담하는 BYOK 유저를 위해, 일반 구독제보다 저렴한 가격에 제한된 토큰만 제공하는 전용 요금제를 별도로 운영한다.
    

### 4.2. 3단계 프리셋 및 컨텍스트 주입 에디터 (Web IDE)

- 초보자부터 전문가까지 아우르는 3단계 템플릿 환경을 웹상에 구현한다.
    
- 작업 공간 내에서 `@` 멘션을 통해 특정 설정 문서(인물, 세계관 등)만 AI의 컨텍스트에 선택적으로 주입하여, 토큰 낭비를 막고 설정 충돌을 방지한다.
    

### 4.3. 지표 기반의 자정 작용 및 큐레이션

- 허수 체류 시간을 제외한 '스크롤 심도 기반 완독률'과 '연독률'을 노출 알고리즘의 최우선 지표로 삼아 양산형 텍스트를 자연 도태시킨다. (산출 알고리즘 및 세부 수치는 [[4. 시스템 아키텍처 및 기술 스택]] 참조)
    

### 4.4. 경량 모델 기반 자동 필터링 (사전 방역)

- 유저가 제출한 시놉시스/하이라이트와 실제 등록된 원고를 비동기 작업 큐(Worker Queue)의 경량화 LLM으로 비교 검증하여, 어그로성 낚시 글의 노출을 차단한다. (파이프라인 상세는 [[4. 시스템 아키텍처 및 기술 스택]] 참조)
    

## 5. 타겟 고객 (Target Audience)

- **창작자 (Creators):**
    
    - **일반 작가:** 복잡한 설정 없이 플랫폼 토큰을 이용해 빠른 연재와 아이디어 구체화를 원하는 창작자.
        
    - **파워 유저:** 자체 API 키를 연동해 프롬프트와 컨텍스트를 정밀 제어하며 대량의 고품질 원고를 집필하려는 테크 친화적 작가.
        
- **독자 (Readers):**
    
    - 빠른 전개와 자극적인 스토리를 추구하며, 모바일/웹 환경에서 스낵 컬처를 소비하는 1030 세대 서브컬처 팬덤.
